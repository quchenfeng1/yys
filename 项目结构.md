# 项目结构（代码文件目录）

> **生成依据**：模块说明书 16 份 + 模块兼容性确认书 + 模块拼接书 + 脚本实现 16 份设计文档
> **分层架构**：桥梁表现层 / 支撑服务层 / 核心运行层 — 共 16 模块
> **语言**：Python 3.10+ ｜ GUI：PyQt5 ｜ 识别：OpenCV ｜ 设备：ADB
