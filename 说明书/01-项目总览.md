## 第一部分 项目总览

### 1.1 项目目标

开发一套基于**图像识别**的《阴阳师》手游自动化脚本，运行于 PC 端，通过连接安卓模拟器（或安卓真机）实现以下完整流程：

```
启动模拟器 → 启动阴阳师 → 开屏动画处理 → 选号 → 选区 → 进入游戏主页面（庭院）
        → 执行日常任务 → 刷副本 → 循环/收尾 → 安全退出
```

### 1.2 核心功能清单

| 序号 | 功能模块 | 说明 |
|------|----------|------|
| F1 | 模拟器/设备连接 | 支持 ADB 连接主流模拟器（雷电、MuMu、夜神等）及安卓真机 |
| F2 | 自动登录流程 | 处理开屏动画、公告、选号、选区，直至进入庭院主界面 |
| F3 | 主界面导航 | 在庭院、町中、探索等界面间导航跳转 |
| F4 | 日常任务 | 悬赏封印、结界突破、花合战、逢魔之时、地域鬼王、阴阳寮任务等 |
| F5 | 副本挑战 | 御魂副本、觉醒副本、探索副本、秘闻副本、业原火等 |
| F6 | 阵容御魂管理 ★ | 对局外调整阵容+御魂、对局内选阵容并锁定，预设可被多副本复用（详见 5.8） |
| F7 | 防封号系统 | 随机化点击、自然鼠标轨迹、行为模拟、运行时长限制 |
| F8 | 配置管理 | 副本入口、界面图、挑战按钮等均可通过配置/素材快速替换 |
| F9 | 日志与监控 | 完整运行日志、截图存档、异常告警 |
| F10 | 图形界面 | 简洁清晰的控制面板，任务勾选、参数设置、一键启停 |
| F11 | 任务调度与时间控制 ★ | 执行规则RepeatRule(单次/每日/每周/每月/隔N天/隔N小时/依赖失效时间)、优先级仲裁、日程表生成、次数控制、**下次执行时间(next_run_time)+执行记录持久化**、UI 可查看修改（见 5.9） |
| F12 | 账号管理与多开 ★ | 多区切换、多开管理（最多1主号+2小号）、小号独立模拟器端口与副本配置、小号仅配合主号刷副本不执行日常（见第十二部分） |

### 1.3 设计原则

1. **配置驱动，素材分离**：所有界面图、按钮坐标、副本入口均存放于外部素材目录与配置文件，版本更新时只需替换图片/改配置，无需改代码。
2. **模块解耦，层次分明**：设备层、识别层、操作层、任务层、UI 层各自独立，通过清晰接口通信。
3. **防封优先，安全第一**：任何点击操作必须经过防封号处理（随机偏移、随机延迟、自然轨迹），杜绝机械式精确点击。
4. **简洁易用，低门槛维护**：界面布局明确，配置项一目了然；新增副本只需"截图 + 填配置"两步。
5. **稳健容错**：识别失败重试、异常自动恢复、卡死检测与自救。
6. **可观测**：全程日志可追溯，关键节点截图存档，便于排查问题。
