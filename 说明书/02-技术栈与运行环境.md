## 第二部分 技术栈与运行环境

### 2.1 技术选型

| 层级 | 技术 | 用途 | 选型理由 |
|------|------|------|----------|
| 开发语言 | Python 3.10+ | 全栈开发 | 生态丰富、开发效率高、图像处理库齐全 |
| 图像识别 | OpenCV (cv2) | 模板匹配、特征点匹配 | 业界标准，精度高，支持灰度/多通道匹配 |
| 截图 | mss / ADB screencap | 高速屏幕捕获 | mss 性能优于 PIL，ADB 用于真机/后台 |
| 操作执行 | ADB input / pyautogui | 点击、滑动、按键 | ADB 用于设备级操作，pyautogui 用于窗口级操作 |
| 设备通信 | ADB (Android Debug Bridge) | 连接模拟器/真机 | 模拟器标准接口，支持后台截图与点击 |
| 界面 | PyQt5 | 图形控制面板 | 跨平台、控件丰富、可做复杂交互 |
| 配置 | YAML + JSON | 任务配置、坐标配置 | YAML 适合人工编辑，JSON 适合程序读写 |
| 日志 | logging + loguru | 运行日志记录 | 灵活的日志分级与文件轮转 |

### 2.2 运行环境要求

- **操作系统**：Windows 10 / 11（64 位）
- **Python**：3.10 及以上
- **模拟器**（默认 MuMu，其他模拟器亦可使用）：
  - **MuMu 模拟器 12.x（默认）★**：ADB 端口 7555 / 16384，自带 adb 路径 `C:/Program Files/Netease/MuMu/nx_main/adb.exe`
  - 雷电模拟器 9.x（ADB 端口 5555）
  - 夜神模拟器 7.x（ADB 端口 62001）
  - 其他主流模拟器均可通过配置 ADB 端口接入
- **模拟器分辨率**：统一设为 **1280×720**（DPI 240），保证识别一致性
- **ADB**：优先使用模拟器自带 adb（MuMu 自带路径见上），亦可配置系统 PATH 或放入项目 tools 目录
- **硬件建议**：i5 及以上 CPU、8GB+ 内存、独立显卡（加速 OpenCV）
