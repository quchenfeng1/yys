## 第八部分 防封号策略详解 ★

> **核心原则**：模拟真人操作的"不完美性"——真人点击会有偏差、会有延迟、会走神、会停顿。脚本必须复现这些特征，而非追求精确高效。

### 8.1 随机化策略

#### 8.1.1 点击位置随机偏移

**绝不点击精确中心点**。在目标中心周围按**正态分布**生成偏移：

```python
def random_offset(self, cx, cy, radius=12):
    # 正态分布偏移（中心概率高，边缘概率低，符合人类瞄准习惯）
    dx = int(np.random.normal(0, radius / 2))
    dy = int(np.random.normal(0, radius / 2))
    # 限制不超出按钮边界
    dx = max(-radius, min(radius, dx))
    dy = max(-radius, min(radius, dy))
    return (cx + dx, cy + dy)
```

- 偏移半径默认 12px（可在配置调整），针对小按钮自动缩小、大按钮自动放大。
- 采用正态分布而非均匀分布，避免"均匀散布"的机器特征。

#### 8.1.2 操作间隔随机延迟

```python
def random_delay(self, base=1.0, jitter=0.6):
    return base + random.uniform(0, jitter)
```

- 每次点击/操作前后插入随机延迟，基础值 + 抖动。
- 不同操作类型设置不同基础延迟（如战斗结算等待更长）。

#### 8.1.3 九宫格区域偏转

参考成熟方案：将屏幕分九宫格，根据点击落点位置对偏移向量进行角度偏转，使大量点击的散点图呈现不规则分布，消除固定模式。

### 8.2 自然鼠标移动轨迹

**禁止瞬移**。点击前生成贝塞尔曲线移动路径，模拟人手移动：

```python
def human_move_path(self, x1, y1, x2, y2):
    # 三阶贝塞尔曲线，加入随机控制点抖动
    steps = random.randint(15, 35)
    path = []
    # 控制点在直线两侧随机偏移
    mid_x = (x1 + x2) / 2 + random.uniform(-30, 30)
    mid_y = (y1 + y2) / 2 + random.uniform(-30, 30)
    for i in range(steps + 1):
        t = i / steps
        # 二次贝塞尔曲线公式
        x = (1-t)**2 * x1 + 2*(1-t)*t * mid_x + t**2 * x2
        y = (1-t)**2 * y1 + 2*(1-t)*t * mid_y + t**2 * y2
        path.append((int(x), int(y)))
    return path
```

- 移动步数随机（15~35 步）
- 控制点随机偏移，曲线不重复
- 每步间插入微小随机停顿（10~50ms）

### 8.3 行为模拟增强

#### 8.3.1 随机长暂停（模拟走神）

```python
def maybe_long_pause(self):
    # 5% 概率触发 5~15 秒的长暂停
    if random.random() < self.long_pause_prob:
        time.sleep(random.uniform(5, 15))
        return True
    return False
```

#### 8.3.2 混淆点击（偶尔点空白）

低概率点击非目标空白区域，模拟误触，打破"每次都精准点中"的特征。

#### 8.3.3 随机操作顺序

- 同一类任务内部步骤顺序可适度打乱（如先领奖励还是先打副本）。
- 日常任务执行顺序支持随机洗牌（配置开关）。

### 8.4 运行限制（硬性安全阀）

| 限制项 | 默认值 | 说明 |
|--------|--------|------|
| 每日最大运行时长 | 8 小时 | 超出自动停止，次日重置 |
| 每日最大操作次数 | 2000 次 | 防止异常循环刷次数 |
| 单副本最大连续次数 | 100 次 | 防止单一行为过久 |
| 连续匹配同一图上限 | 5 次 | 疑似卡死则停止 |
| 最小操作间隔 | 0.8 秒 | 防止过快操作 |
| 推荐单次运行时长 | ≤3 小时 | 软建议，超时提醒 |

**实现**：`AntiDetect.check_run_limit()` 在每次操作前检查，超限抛出 `AntiBanRiskError` 中止运行。

### 8.5 风险控制清单

- ✅ 所有点击经防封号引擎（随机偏移 + 自然轨迹 + 随机延迟）
- ✅ 不使用高速模式，保持自然节奏
- ✅ 限制每日运行时长与次数
- ✅ 随机长暂停模拟走神
- ✅ 偶尔混淆点击空白区域
- ✅ 任务顺序可随机化
- ❌ 禁止 24 小时连续运行
- ❌ 禁止固定精确坐标点击
- ❌ 禁止过短操作间隔（<0.5s）
- ❌ 禁止单一副本无限循环
