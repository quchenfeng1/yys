## 第二步：编写任务逻辑

### 2.1 需求分析

御魂副本第八层需要：
1. **SETUP**：从庭院 → 探索入口 → 御魂副本 → 第八层
2. **LOOP**：检查体力 → 发起战斗 → 等待结算 → 领奖（循环 10 次）
3. **TEARDOWN**：返回庭院（已有 ReturnHall）

### 2.2 引用通用模块

编辑 `tasks/special/soul_8.py`，取消需要的 import 注释：

```python
# ==================== ② 导入依赖 ====================
from tasks.base.task_step import TaskStep, StepResult
from tasks.base.task_context import TaskContext
from tasks.base.task_graph import TaskGraph

from tasks.common.close_popup    import ClosePopup
from tasks.common.return_hall    import ReturnHall
from tasks.common.battle_loop    import BattleLoop      # ← 取消注释
from tasks.common.check_stamina  import CheckStamina    # ← 取消注释
```

### 2.3 编写特化步骤

在骨架的 `# ==================== ③ 特化步骤 ====================` 下方添加：

```python
class EnterYuhunDungeon(TaskStep):
    """进入御魂副本第八层"""
    name = "enter_yuhun"
    is_generic = False
    timeout = 30

    def execute(self, context: TaskContext) -> StepResult:
        exe = context.executor

        # 1. 从庭院点击探索入口
        if not exe.click_image("主界面/按钮-探索入口", timeout=5):
            return StepResult.fail("未找到探索入口")

        # 2. 点击御魂副本入口
        if not exe.click_image("探索/按钮-御魂副本", timeout=5):
            return StepResult.fail("未找到御魂副本入口")

        # 3. 选择第八层
        if not exe.click_image("探索/按钮-第八层", timeout=3):
            return StepResult.fail("未找到第八层按钮")

        # 4. 确认进入
        exe.click_if_exists("通用/按钮-确定")
        return StepResult.success("已进入御魂第八层")


class StartBattle(TaskStep):
    """点击挑战发起战斗"""
    name = "start_battle"
    is_generic = False
    timeout = 15

    def execute(self, context: TaskContext) -> StepResult:
        if not context.executor.click_image("战斗/按钮-挑战", timeout=5):
            return StepResult.fail("未找到挑战按钮")
        return StepResult.success("战斗已发起")
```

### 2.4 编排 TaskGraph

修改 `build_graph()` 函数：

```python
def build_graph(context: TaskContext) -> TaskGraph:
    g = TaskGraph("soul_8")

    # SETUP 阶段（执行一次）
    g.add_step("close_popup", ClosePopup())
    g.add_step("enter",       EnterYuhunDungeon())

    # LOOP 阶段（循环 N 次）
    g.add_step("stamina",     CheckStamina())
    g.add_step("start",       StartBattle())
    g.add_step("battle",      BattleLoop(
        times=context.task_config.get("loop_count", 10)
    ))

    # TEARDOWN 阶段（执行一次）
    g.add_step("go_home",     ReturnHall())

    # 连线
    g.set_entry("close_popup")
    g.add_edge("close_popup", "enter")
    g.add_edge("enter",       "stamina")
    g.add_edge("stamina",     "start")
    g.add_edge("start",       "battle")
    g.add_edge("battle",      "stamina")      # ← LOOP 回到体力检查
    g.add_edge("go_home",     None)            # teardown 后结束

    # 条件边：体力不足 → 跳过
    def stamina_skip(result):
        return result.status == "skip"
    g.add_edge("stamina", "go_home", condition=stamina_skip)

    g.set_error_branch("go_home")
    return g
```

> ⚠ **注意**：TaskGraph 不支持循环边。上面的 `stamina → start → battle → stamina` 循环在代码中不可行，正确做法是把 `CheckStamina → StartBattle → BattleLoop` 放在一个步骤内让 BattleLoop 自循环。这里仅为概念示意。
>
> **正确写法**：
> ```
> SETUP: ClosePopup → EnterYuhunDungeon
> LOOP:  BattleLoop(times=10, stamina_check=True)
> TEARDOWN: ReturnHall
> ```

## 第六步：调试排查

### 6.1 素材找不到

```
如果日志显示 "未找到探索入口" →
  ① 将日志级别切到 DEBUG，查看每次匹配的置信度
  ② 降低阈值测试：executor.click_image("主界面/按钮-探索入口", threshold=0.65)
  ③ 检查素材是否包含过多背景 → 重新裁剪
```

### 6.2 流程卡住

```
如果任务执行到某步不再前进 →
  ① 任务有 timeout，超时后会自动跳到 error 分支
  ② 检查异常截图 logs/snapshots/ → 看当时画面
  ③ 手动模拟操作，确认按钮位置是否变化
```

### 6.3 调度不触发

```
如果任务没出现在队列中 →
  ① 检查 enabled 是否为 true
  ② 检查 next_run_time 是否已到
  ③ 检查是否超出 max_daily 上限
```

> 详细排查清单见 `测试与调试指南.md`
