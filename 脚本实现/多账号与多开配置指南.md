# 多账号与多开配置指南 v1.0

> **文档性质**：主号小号设置、多模拟器配置、任务范围划分  ｜  **配套**：配置体系设计指导 / 15-账号管理模块

---

## 一、概述

脚本支持多模拟器多开，每个模拟器绑定一个游戏账号。账号分为两种角色：

| 角色 | 标识 | 可执行任务 | 典型用途 |
|------|------|-----------|---------|
| **主号** (main) | `role: "main"` | 全部任务（日常+副本+活动） | 大号，做所有事 |
| **小号** (sub) | `role: "sub"` | 仅 permanent 副本 | 资源小号，只产出 |

> ⚠ 当前账号切换功能由 01-设备连接模块（EmulatorManager/ADBClient）直接处理，15-账号管理模块的 `AccountManager` 类为设计目标。

## 二、accounts.yaml 配置

```yaml
main_account:
  account_id: "main"
  role: "main"
  nickname: "主号"
  server: "春樱共斗"
  adb_port: 16384
  device_id: "127.0.0.1:16384"
  enabled: true

sub_accounts:
  - account_id: "sub1"
    role: "sub"
    nickname: "小号1"
    server: "春樱共斗"
    adb_port: 16416
    device_id: "127.0.0.1:16416"
    enabled: true
    dungeon_tasks:             # 小号专属副本任务
      - name: "yuhun"
        enabled: true
        times: 20
        team_id: "yuhun_speed"

  - account_id: "sub2"
    role: "sub"
    nickname: "小号2"
    server: "秋风忆梦"
    adb_port: 16448
    device_id: "127.0.0.1:16448"
    enabled: false             # 未启用
    dungeon_tasks: []
```

### 字段说明

| 字段 | 说明 |
|------|------|
| `account_id` | 账号唯一标识，不可重复 |
| `role` | `"main"` 或 `"sub"` |
| `nickname` | 显示名（UI 状态栏展示） |
| `server` | 游戏服务器名 |
| `adb_port` | 该账号模拟器的 ADB 端口 |
| `device_id` | ADB 设备地址（`127.0.0.1:{port}`） |
| `enabled` | 是否启用此账号 |
| `dungeon_tasks` | （仅小号）专属的副本任务配置 |

## 三、多开模拟器设置

### 3.1 MuMu 模拟器多开

```
① MuMu 模拟器 → 多开管理器
② 创建多个实例（主号 + 小号1 + 小号2）
③ 每个实例单独安装阴阳师
④ 设置 → 其他 → ADB 调试 → 开启
⑤ 记录每个实例的 ADB 端口：
    实例0 (主号): 16384
    实例1 (小号1): 16416
    实例2 (小号2): 16448
```

### 3.2 ADB 端口规律

| 模拟器 | 端口规律 |
|--------|---------|
| MuMu 12 | 16384 + (实例编号 × 32) |
| 雷电 | 5555 + (实例编号 × 2) |
| 夜神 | 62001 + (实例编号) |

### 3.3 连接验证

```bash
# 列出所有已连接设备
adb devices

# 预期输出：
# 127.0.0.1:16384  device
# 127.0.0.1:16416  device
# 127.0.0.1:16448  device
```

## 四、任务范围划分

### 4.1 主号任务范围

主号执行所有分类的任务：

```yaml
# tasks.yaml
daily:       # 日常任务 → 主号
permanent:   # 常驻副本 → 主号 + 小号
event:       # 活动任务 → 主号
special:     # 特殊任务 → 主号
```

### 4.2 小号任务范围

小号只执行 `permanent` 分类的任务（御魂、觉醒等产出副本），以及 `dungeon_tasks` 中定义的专属副本。

### 4.3 调度行为

```
Scheduler 生成日程表
  → 按 priority 排序
  → 标记任务所属账号
  → ScriptWorker 执行每个任务前检查：
      if task.account_scope == "sub_only" and current_account.role == "main":
          skip
```

> 注：当前账号范围过滤逻辑在 ScriptWorker 中通过 `account_role` 状态键判断，尚未完全实现 `dungeon_tasks` 的细粒度过滤。

## 五、账号切换流程

```
主号任务队列执行完毕
  → 检查是否有小号有待执行任务
  → 有 → 断开当前 ADB 连接
  → 连接小号模拟器 ADB 端口
  → 更新状态: current_account = "sub1"
  → 执行小号任务
  → 完成后切回主号
```

## 七、常见问题

| 问题 | 解决 |
|------|------|
| 多个模拟器 ADB 端口冲突 | MuMu 多开自动分配不同端口，手动多开需要改模拟器设置 |
| 小号任务不执行 | 检查 `enabled: true`、检查 `dungeon_tasks` 配置 |
| 切换账号后识图失败 | 不同模拟器可能有不同分辨率，确保全部为 1280×720 |
| 只想跑主号 | 将所有小号的 `enabled` 设为 `false` |
