# 游戏更新后恢复流程 v1.0

> **文档性质**：应急处置手册——游戏版本更新后素材漂移、流程变化的应对  ｜  **配套**：素材体系设计指导 / 测试与调试指南

---

## 一、更新影响类型

游戏版本更新可能导致以下问题：

| 影响类型 | 表现 | 影响范围 |
|---------|------|---------|
| **UI 位移** | 按钮位置变化，素材仍能匹配但点不到 | 中 |
| **UI 改版** | 按钮外观变化，素材匹配失败 | 高 |
| **流程变化** | 新增/删除步骤，原有任务逻辑不适用 | 高 |
| **新增弹窗** | 更新后首次进入出现新公告/引导 | 中 |
| **分辨率适配** | 游戏更改了默认分辨率 | 低 |

---

## 二、快速诊断

### 2.1 启动脚本观察终端

```
如果看到：
  "未找到「XXX」" → UI 改版，素材需要更新
  "点击失败"     → UI 位移，坐标可能偏移
  "步骤超时"     → 流程变化或新增弹窗阻塞
```

### 2.2 检查异常截图

```
logs/snapshots/{时间戳}_{任务名}_{步骤名}.png
```

对比异常截图与素材，确认是否为素材漂移。

### 2.3 使用 DEBUG 日志

```
① UI「脚本配置 → 日志配置」→ 日志级别切到 DEBUG
② 重新运行任务
③ 观察每条 click_image 的匹配置信度
④ 置信度 < 0.5 → 素材已不匹配
```

## 三、恢复流程

### 3.1 素材更新（UI 改版）

```
① 模拟器运行游戏 → 到达目标页面
② 截图 → 裁剪新按钮/标志
③ 替换 assets/ 中的旧素材文件（保持文件名不变）
④ 重启脚本（Recognizer 将重新加载素材缓存）
⑤ 重新运行任务 → 确认匹配通过
```

### 3.2 坐标修正（UI 位移）

```
① 素材仍能匹配到但点击位置不对
② 说明 offset 后在正确坐标周围但未能命中
③ 检查素材裁剪区域是否包含按钮的全部点击区域
④ 必要时扩大裁剪范围或降低偏移半径
```

### 3.3 流程适配（流程变化）

```
① 游戏更新后新增了确认步骤
② 找到卡住的位置 → 对应修改任务的 build_graph()
③ 新增一个 ClosePopup 或 click_image 步骤
④ 如果流程简化（删除了步骤），移除对应步骤
```

### 3.4 新增弹窗处理

```
① 更新后首次进入出现新公告弹窗
② ClosePopup 通用模块已覆盖大多数弹窗
③ 如果 ClosePopup 未能关闭 → 检查新弹窗的关闭按钮样式
④ 添加新素材到 assets/通用/ 目录
⑤ 更新 ClosePopup.CLOSE_IMAGES 列表
```

## 四、验证检查清单

更新后逐项确认：

```
□ 1. 启动脚本 → 模拟器连接正常
□ 2. 登录流程正常 → 能进入庭院
□ 3. 主界面识别正常（OpenBottomMenu 通过）
□ 4. 依次执行每个任务 → 查看终端日志
□ 5. 每个 click_image 的匹配置信度 > 0.7
□ 6. 战斗识别正常（胜利/失败标志）
□ 7. 返回庭院正常
□ 8. 无新增 ERROR 日志
```

---

## 五、预防措施

| 措施 | 说明 |
|------|------|
| 素材备份 | 定期备份 `assets/` 目录，更新后可对比变更 |
| 版本标注 | 在素材目录中添加 `version.txt` 记录适配的游戏版本号 |
| 灰度测试 | 更新后先用 DEBUG 档 + 单次执行测试每个任务 |
| 保守参数 | 更新后可临时提高识别阈值（0.85→0.75），确保能找到 |
```

---

## 六、常见更新场景速查

| 场景 | 处理 |
|------|------|
| 周三例行维护 | 通常只改活动 Banner，更新活动入口素材 |
| 大版本更新 | 可能全面改版 UI → 逐一检查所有素材 |
| 新式神/新御魂 | 不影响脚本（不涉及识图） |
| 新副本上线 | 编写新任务 + 新素材 |
| 活动开启/结束 | 启用/禁用活动任务配置 + 更新活动素材 |
