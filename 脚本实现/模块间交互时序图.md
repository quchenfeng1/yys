## 一、系统启动时序

```mermaid
sequenceDiagram
    participant BAT as 启动.bat
    participant MAIN as main.py
    participant MW as MainWindow<br/>(11-用户界面)
    participant CM as ConfigManager<br/>(06-配置管理)
    participant TM as TaskManager<br/>(13-任务文件管理)
    participant IM as ImageManager
    participant EB as EventBus<br/>(08-事件通信)
    participant SCH as Scheduler<br/>(05-时间调度)
    participant UI_PANELS as UI子面板

    BAT->>MAIN: pythonw 启动
    MAIN->>MAIN: 创建 QApplication
    MAIN->>MW: new MainWindow()
    
    activate MW
    MW->>CM: ConfigManager()
    CM-->>MW: 加载 global.yaml / tasks.yaml / accounts.yaml
    
    MW->>TM: TaskManager()
    TM->>TM: scan_all() — 扫描 tasks/ 四类目录
    TM-->>MW: 返回 TaskModule 列表
    
    MW->>IM: ImageManager()
    IM-->>MW: 扫描 assets/ 素材
    
    MW->>MW: _init_ui()
    MW->>UI_PANELS: 创建 MenuTree / ControlBar / TaskQueuePanel / LogPanel / ...
    
    MW->>SCH: Scheduler(config, state_manager)
    SCH->>SCH: load_tasks_from_config()
    SCH->>SCH: load_state() — 从 task_state.json 恢复
    SCH->>SCH: build_schedule() — 扫描到期任务
    SCH->>EB: publish(SCHEDULE_UPDATED)
    EB->>UI_PANELS: 通知 TaskQueuePanel 刷新
    
    MW->>MW: 连接信号 (启动/停止按钮 → _on_start/_on_stop)
    deactivate MW
    
    MAIN->>MAIN: app.exec_() — Qt 事件循环
```

## 三、运行启动 → 登录时序（核心）

```mermaid
sequenceDiagram
    participant USER as 用户
    participant MW as MainWindow<br/>(11-用户界面)
    participant SW as ScriptWorker<br/>(09-运行控制)
    participant SCH as Scheduler<br/>(05-时间调度)
    participant EMU as EmulatorManager<br/>(01-设备连接)
    participant ADB as ADBClient
    participant REC as Recognizer<br/>(02-图像识别)
    participant AD as AntiDetect<br/>(03-防封策略)
    participant EXE as Executor<br/>(14-执行器)
    participant LF as LoginFlow<br/>(16-应用引导)
    participant EB as EventBus

    USER->>MW: 点击「启动」
    MW->>SW: new ScriptWorker(emulator, port, scheduler=...)
    MW->>SW: worker.start() — QThread 启动
    
    activate SW
    Note over SW: === Step1: 加载配置 ===
    SW->>SW: ConfigManager()
    SW->>SCH: load_tasks_from_config()
    SW->>SCH: load_state()
    SW->>SCH: build_schedule()
    SCH->>EB: publish(SCHEDULE_UPDATED)
    
    Note over SW: === Step2: 连接模拟器 ===
    SW->>EMU: ensure_running(adb, port, stop_check)
    EMU->>ADB: connect("127.0.0.1:5555")
    ADB-->>EMU: 连接成功
    EMU-->>SW: True
    
    Note over SW: === Step3: 分辨率检查 ===
    SW->>ADB: get_screen_size()
    ADB-->>SW: (1280, 720)
    
    Note over SW: === Step4: 启动App ===
    SW->>ADB: launch_app(package, activity)
    ADB-->>SW: 已启动
    
    Note over SW: === Step5: 素材加载 ===
    SW->>SW: _load_images() — 所需图片→assets/
    
    Note over SW: === Step6: 初始化核心模块 ===
    SW->>REC: Recognizer(screenshot_func, threshold)
    SW->>AD: AntiDetect(config)
    SW->>EXE: Executor(adb, recognizer, anti_detect)
    
    Note over SW: === Step7: 素材校验 ===
    SW->>SW: _check_images() — 统计缺失素材
    
    Note over SW: === Step8: 登录流程 ===
    SW->>LF: LoginFlow(executor, recognizer, config)
    LF->>EXE: click_image("scenes/login/splash_skip")
    EXE->>REC: find("scenes/login/splash_skip")
    REC->>ADB: screenshot()
    ADB-->>REC: np.ndarray
    REC-->>EXE: MatchResult(x, y)
    EXE->>AD: random_offset(x, y)
    AD-->>EXE: (safe_x, safe_y)
    EXE->>ADB: click(safe_x, safe_y)
    EXE->>AD: sleep(0.8, 0.5)
    EXE->>AD: record_action()
    Note over LF,ADB: ...反复识图+点击直到进入庭院...
    LF-->>SW: success=True
    
    SW->>SW: _run_schedule_loop()
    deactivate SW
```

## 四、调度循环时序（核心）

```mermaid
sequenceDiagram
    participant SW as ScriptWorker<br/>(09-运行控制)
    participant SCH as Scheduler<br/>(05-时间调度)
    participant EB as EventBus
    participant UI as TaskQueuePanel<br/>(11-用户界面)
    participant FS as 文件系统
    participant TASK as TaskStep 子类<br/>(04-任务引擎)
    participant CTX as TaskContext
    participant EXE as Executor<br/>(14-执行器)

    loop while not is_stopped()
        SW->>SCH: build_schedule()
        SCH->>SCH: 遍历所有启用任务 → is_due() + check_times_limit()
        SCH->>SCH: 按 priority 升序排序
        SCH->>EB: publish(SCHEDULE_UPDATED)
        EB->>UI: 刷新任务队列卡片
        
        SW->>SCH: get_next_task()
        alt 无到期任务
            SCH-->>SW: None
            SW->>SW: sleep(5)
        else 有到期任务
            SCH-->>SW: "soul_10"
            
            SW->>EB: publish(TASK_STARTED, task_name="soul_10")
            EB->>UI: 高亮当前任务, 显示进度
            
            SW->>FS: 遍历 tasks/{daily,permanent,special,event}/soul_10.py
            FS-->>SW: 找到 tasks/special/soul_10.py
            
            SW->>SW: importlib.import_module("tasks.special.soul_10")
            SW->>SW: inspect → 查找 TaskStep 子类 (is_generic=False)
            
            SW->>CTX: TaskContext(task_name, task_config, executor, recognizer, log)
            SW->>TASK: step.execute(context)
            
            activate TASK
            Note over TASK,EXE: 任务内部执行 (详见 §五)
            TASK-->>SW: StepResult(status="success")
            deactivate TASK
            
            SW->>SCH: mark_done("soul_10", success=True)
            SCH->>SCH: 推进 next_run_time (按 repeat 规则)
            SCH->>SCH: fail_streak 归零
            SCH->>SCH: save_state() — 原子写盘
            
            SW->>EB: publish(TASK_DONE, task_name="soul_10", success=True)
            EB->>UI: 清除当前任务卡片, 刷新队列
        end
        
        SW->>SW: 检查 is_stopped()
    end
```

## 五、任务执行内部时序（TaskStep → Executor 全链路）

```mermaid
sequenceDiagram
    participant SW as ScriptWorker
    participant CTX as TaskContext
    participant GRAPH as TaskGraph<br/>(04-任务引擎)
    participant STEP as 特化步骤<br/>(EnterDungeon)
    participant GEN as 通用模块<br/>(BattleLoop)
    participant EXE as Executor<br/>(14-执行器)
    participant REC as Recognizer<br/>(02-图像识别)
    participant AD as AntiDetect<br/>(03-防封策略)
    participant ADB as ADBClient<br/>(01-设备连接)
    participant EB as EventBus

    SW->>CTX: TaskContext(task_name, task_config, executor, recognizer, log)
    SW->>GRAPH: build_graph(context).run(context)
    
    activate GRAPH
    Note over GRAPH: === SETUP 阶段 ===
    
    GRAPH->>STEP: ClosePopup.execute(context)
    STEP->>EXE: click_if_exists("common/ui/close_btn")
    EXE->>REC: find("common/ui/close_btn")
    REC->>ADB: screenshot()
    ADB-->>REC: np.ndarray
    REC->>REC: cv2.matchTemplate()
    REC-->>EXE: MatchResult(center=(200,300), confidence=0.92)
    EXE->>AD: random_offset(200, 300)
    AD-->>EXE: (203, 297)
    EXE->>AD: check_run_limit()
    EXE->>ADB: click(203, 297)
    EXE->>AD: sleep(0.8, 0.5)
    EXE->>AD: record_action()
    EXE-->>STEP: True
    STEP-->>GRAPH: StepResult.success("关闭 1 个弹窗")
    
    GRAPH->>STEP: EnterDungeon.execute(context)
    STEP->>EXE: click_image("副本/按钮-八岐大蛇", timeout=5)
    Note over EXE,ADB: ...识图→偏移→点击 全链路...
    EXE-->>STEP: True
    STEP->>EXE: click_image("副本/按钮-第十层", timeout=3)
    EXE-->>STEP: True
    STEP-->>GRAPH: StepResult.success("已进入副本第10层")
    
    Note over GRAPH: === LOOP 阶段 (BattleLoop 内部循环 N 次) ===
    
    GRAPH->>GEN: BattleLoop(times=3).execute(context)
    activate GEN
    loop i = 0..2
        GEN->>REC: wait_any(["common/battle/victory", "common/battle/defeat"], timeout=180)
        REC->>ADB: screenshot() (轮询)
        REC-->>GEN: ("common/battle/victory", MatchResult)
        GEN->>EXE: click_if_exists("common/battle/confirm_btn")
        Note over EXE,ADB: 识图→偏移→点击 结算按钮
        EXE-->>GEN: True
        GEN->>EXE: random_sleep(1, 2)
    end
    GEN-->>GRAPH: StepResult.success("完成 3 轮战斗")
    deactivate GEN
    
    Note over GRAPH: === TEARDOWN 阶段 ===
    
    GRAPH->>STEP: ReturnHall.execute(context)
    STEP->>EXE: click_if_exists("common/ui/back_btn")
    STEP->>REC: exists("scenes/courtyard/main")
    Note over STEP,REC: 反复返回直到识别到庭院
    
    alt 任一步骤失败
        GRAPH->>STEP: ErrorReturn (错误分支)
        STEP-->>GRAPH: StepResult.skip("任务跳过")
    end
    
    GRAPH-->>SW: True (全部成功)
    deactivate GRAPH
    
    SW->>EB: publish(TASK_DONE, task_name="soul_10", success=True)
```

## 六、用户停止时序

```mermaid
sequenceDiagram
    participant USER as 用户
    participant MW as MainWindow
    participant SW as ScriptWorker<br/>(09-运行控制)
    participant STEP as 当前步骤<br/>(04-任务引擎)
    participant SCH as Scheduler<br/>(05-时间调度)
    participant EB as EventBus
    participant UI as UI面板

    USER->>MW: 点击「停止」
    MW->>SW: worker.stop()
    SW->>SW: _stop_flag = True (线程安全锁)
    
    Note over SW,STEP: 等待当前步骤完成 (步骤边界检查)
    
    SW->>SW: 调度循环内检查 is_stopped()
    alt 正在执行步骤
        Note over STEP: 步骤内部原子执行,不中断
        STEP-->>SW: StepResult
    end
    
    SW->>SW: is_stopped() → True → 退出循环
    SW->>SCH: save_state() — 持久化所有 next_run_time
    SW->>MW: finished_signal.emit(True, "用户停止")
    
    MW->>EB: publish(STATE_CHANGED, run_status="idle")
    EB->>UI: ControlBar 恢复按钮状态
    EB->>UI: StatusBar 显示「待机」
```

## 七、事件通信全景

```mermaid
sequenceDiagram
    participant UI as 11-用户界面
    participant PB as 10-参数桥接<br/>(设计目标层)
    participant RC as 09-运行控制<br/>(ScriptWorker)
    participant SCH as 05-时间调度<br/>(Scheduler)
    participant TE as 04-任务引擎<br/>(TaskGraph)
    participant DC as 01-设备连接<br/>(ADBClient)
    participant SM as 07-状态管理<br/>(StateManager)
    participant MON as 12-日志监控<br/>(Monitor)
    participant CM as 06-配置管理<br/>(ConfigManager)
    participant EB as 08-事件通信总线

    Note over EB: ══════ 启动阶段 ══════
    UI->>PB: 用户点击启动 (当前直接调用)
    PB->>EB: publish(start_requested)
    EB->>RC: 收到 start_requested
    RC->>RC: _execute() → 8步初始化
    RC->>EB: publish(run_started)
    EB->>UI: 更新状态为「运行中」
    
    Note over EB: ══════ 调度阶段 ══════
    RC->>SCH: build_schedule()
    SCH->>EB: publish(SCHEDULE_UPDATED, tasks=[...])
    EB->>UI: TaskQueuePanel 刷新队列
    
    RC->>SCH: get_next_task() → "soul_10"
    RC->>EB: publish(TASK_STARTED, task_name="soul_10")
    EB->>UI: 高亮当前任务
    EB->>SM: 更新 current_task
    
    Note over EB: ══════ 执行阶段 ══════
    RC->>TE: step.execute(context)
    TE->>EB: publish(STEP_DONE, step="enter_dungeon", status="success")
    EB->>UI: 更新步骤进度
    EB->>SM: 更新 current_step
    
    RC->>EB: publish(TASK_DONE, task_name="soul_10", success=True)
    EB->>UI: 清除当前任务
    EB->>SM: 清除 current_task
    
    Note over EB: ══════ 运行中异常 ══════
    DC->>EB: publish(CONNECTION_LOST, device="127.0.0.1:5555")
    EB->>UI: 连接图标变红
    EB->>RC: (预留: 暂停调度)
    
    DC->>EB: publish(CONNECTION_RESTORED)
    EB->>UI: 连接图标恢复
    
    Note over EB: ══════ 每日重置 ══════
    SCH->>SCH: 检测到跨日 (00:00)
    SCH->>EB: publish(DAILY_RESET)
    EB->>SCH: 重置 today_count
    EB->>UI: 刷新队列
    
    Note over EB: ══════ 停止阶段 ══════
    UI->>PB: 用户点击停止
    PB->>EB: publish(stop_requested)
    EB->>RC: 收到 stop_requested
    RC->>RC: is_stopped() → 退出循环
    RC->>EB: publish(run_stopped)
    EB->>UI: 更新状态为「待机」
    EB->>SM: 更新 run_status="idle"
    
    Note over EB: ══════ 持续日志 ══════
    MON->>EB: publish(LOG_RECORD, level, message)
    EB->>UI: LogPanel 追加日志行
```

## 九、模块间调用关系速查

```
调用层级 (上→下):

11-用户界面 ─── 直接持有 ──→ 06-配置管理
    │                       13-任务文件管理
    │                       素材管理
    │                       05-时间调度
    │
    └── 创建并启动 ──→ 09-运行控制 (ScriptWorker QThread)
                          │
                          ├──→ 05-时间调度 (Scheduler)
                          ├──→ 01-设备连接 (EmulatorManager / ADBClient)
                          ├──→ 02-图像识别 (Recognizer)
                          ├──→ 03-防封策略 (AntiDetect)
                          ├──→ 14-执行器 (Executor)
                          │      ├──→ 02-图像识别
                          │      ├──→ 03-防封策略
                          │      └──→ 01-设备连接
                          ├──→ 04-任务引擎 (动态 import → execute)
                          │      ├──→ 14-执行器 (通过 context.executor)
                          │      └──→ 02-图像识别 (通过 context.recognizer)
                          └──→ 16-应用引导 (LoginFlow)

08-事件通信总线 ←→ 所有模块 (发布/订阅)
07-运行时状态管理 ←→ 所有模块 (读写共享状态)
12-日志监控中心 ←→ 所有模块 (记录日志)
```

> **注意**：当前实现中 UI (MainWindow) 直接持有核心模块引用，未经过 10-参数桥接。10-参数桥接为设计目标层，计划在未来版本中作为 UI↔逻辑 的唯一通道。
