## 二、Python 环境安装

### 2.1 安装 Python

从 [python.org](https://www.python.org/downloads/) 下载 Python 3.10+，安装时勾选 **"Add Python to PATH"**。

### 2.2 创建虚拟环境（推荐）

```powershell
cd d:\yys
python -m venv .venv
.venv\Scripts\activate
```

### 2.3 安装依赖

```powershell
pip install -r requirements.txt
```

**依赖清单**：

| 包 | 版本 | 用途 |
|---|------|------|
| `opencv-python` | ≥4.8.0 | 图像识别（模板匹配） |
| `numpy` | ≥1.24.0 | 图像数组处理 |
| `PyQt5` | ≥5.15.9 | GUI 界面 |
| `PyYAML` | ≥6.0 | YAML 配置文件解析 |
| `loguru` | ≥0.7.0 | 结构化日志 |
| `Pillow` | ≥10.0.0 | 图片读取（兼容中文路径） |
| `mss` | ≥9.0.1 | 屏幕截图（预留） |
| `pyautogui` | ≥0.9.54 | 自动化操作（预留） |

## 三、模拟器配置

### 3.1 安装模拟器

推荐 **MuMu 模拟器 12**（对 ADB 支持最好），也可选择雷电或夜神。

### 3.2 分辨率设置

```
必须设置为: 1280 × 720 (横屏)
```

在模拟器设置中：显示 → 分辨率 → 自定义 → 宽 1280, 高 720。

> **重要**：分辨率不匹配会导致所有图像识别失败。

### 3.3 安装阴阳师

在模拟器的应用商店中搜索并安装"阴阳师"。

### 3.4 ADB 连接验证

```powershell
# MuMu 默认 ADB 端口: 16384
adb connect 127.0.0.1:16384

# 雷电默认 ADB 端口: 5555
adb connect 127.0.0.1:5555

# 夜神默认 ADB 端口: 62001
adb connect 127.0.0.1:62001

# 验证连接
adb devices
# 预期输出: 127.0.0.1:16384  device
```

### 3.5 配置 ADB 路径

编辑 `config/global.yaml`：

```yaml
adb:
  device_id: "127.0.0.1:16384"   # 对应你的模拟器端口
  path: "C:/Program Files/Netease/MuMu/nx_main/adb.exe"  # ADB 路径
  port: 16384

emulator:
  type: "mumu"                    # ldplayer / mumu / nox
  auto_launch: true               # 自动启动模拟器
```

## 四、首次运行清单

```
□ 1. Python 虚拟环境已创建并激活

□ 9. 状态栏显示「已停止」「未连接」（正常，因为还没连接设备）
□ 10. 点击「启动」→ 观察终端日志 → 确认能连接模拟器
```

## 五、启动方式

### 方式一：双击启动（推荐日常使用）

```
双击 启动.bat
```

`启动.bat` 内容：

```batch
@echo off
cd /d "%~dp0"
REM 尝试多个 Python 安装路径
REM 使用 pythonw.exe 无窗口运行
```

`pythonw.exe` 无控制台窗口，适合日常使用。

### 方式二：命令行启动（调试用）

```powershell
cd d:\yys
.venv\Scripts\activate
python main.py
```

命令行启动可看到完整的 stdout/stderr 输出（即使内置终端也在运行）。

## 六、素材准备

首次运行前，需要准备游戏截图素材：

```
1. 启动脚本 → 连接模拟器 → 登录游戏（到庭院主界面）
2. 对需要的每个按钮/标志进行截图
3. 裁剪为 PNG，按命名规范放入 assets/ 对应分区
4. 在 UI「图片配置」面板中确认素材已加载
```

> 详见 `素材体系设计指导.md`

## 九、常见部署问题

| 问题 | 原因 | 解决 |
|------|------|------|
| `ModuleNotFoundError: opencv` | 依赖未安装 | `pip install -r requirements.txt` |
| `ImportError: PyQt5` | PyQt5 安装失败 | `pip install PyQt5 --only-binary :all:` |
| ADB 连接超时 | 端口不对或模拟器未开启 ADB | MuMu: 设置→其他→开启 ADB 调试 |
| 启动后无窗口 | 使用了 pythonw.exe | 改用 `python main.py` 调试，或检查启动.bat |
| 日志乱码 | Windows 终端编码 | 内置终端（UI 右侧）不受影响 |
| `ConfigError` | YAML 格式错误 | 检查缩进（2 空格）、检查冒号后有空格 |
