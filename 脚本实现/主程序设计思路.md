# 主程序设计思路 v3.0

> **文档性质**：基于16模块架构的程序设计总览  ｜  **版本**：v3.0（持续调度循环 + 优先队列）

---

## 一、程序启动流程

```
启动.bat（pythonw 无窗口）
  └─ main.py
       │  创建 QApplication
       │  创建 MainWindow（三栏布局）
       │     ├─ 左: MenuTree（菜单导航）
       │     ├─ 中: ControlBar + TaskQueuePanel + 可切换面板
       │     └─ 右: LogPanel（日志+终端）
       │
       ├─ MainWindow.__init__()
       │   ├─ ConfigManager()           ← 加载 global.yaml / tasks.yaml
       │   ├─ TaskManager()             ← 扫描 tasks/ 目录
       │   ├─ ImageManager()            ← 管理 assets/ 素材
       │   ├─ _init_ui() → 创建所有子面板
       │   ├─ Scheduler()               ← 加载 tasks.yaml → build_schedule()
       │   │   → 发布 SCHEDULE_UPDATED → UI 显示任务队列
       │   └─ 信号连接（启动/停止/暂停按钮 → _on_start/_on_stop）
       │
       └─ app.exec_()  ← Qt 事件循环
```

## 三、运行时数据流

### 3.1 点击启动

```
MainWindow._on_start()
  ├── 创建 ScriptWorker（注入 Scheduler）
  ├── worker.start() → QThread 启动
  └── ScriptWorker._execute()
        ├── Step1: 加载配置 → Scheduler.load_tasks_from_config()
        │          → build_schedule() → 发布 SCHEDULE_UPDATED
        ├── Step2: 连接模拟器（ensure_running + stop_check）
        ├── Step3-7: 分辨率 → 启动App → 素材 → 初始化识别器/执行器
        ├── Step8: LoginFlow 登录
        │     ├── 成功 → _run_schedule_loop()
        │     └── 失败 → 停止
        └── _run_schedule_loop() ← 持续调度循环
```

### 3.2 调度循环（单线程优先队列）

```
while not is_stopped():
    ┌── ① scheduler.build_schedule()      → 扫描到期任务 → 按 priority 排序
    │                                        → 发布 SCHEDULE_UPDATED
    ├── ② 新任务按 priority 插入 _task_queue（去重）
    ├── ③ if 队列空: sleep(5); continue
    ├── ④ task = _task_queue.pop(0)        → FIFO 出队
    ├── ⑤ 动态导入 → TaskStep.execute(context)
    ├── ⑥ scheduler.mark_done(name, success)
    └── ⑦ 发布 TASK_DONE → UI 刷新
```

### 3.3 任务执行细节

```
TaskStep.execute(context)
  │  context 包含: executor, recognizer, task_config, log
  │
  ├── context.recognizer.find("主界面/识别-个人名片")
  │     → Recognizer.find(template, region, threshold)
  │     → 截图 → 灰度转换 → cv2.matchTemplate → MatchResult
  │
  ├── context.executor.click_if_exists("主界面/按钮-打开底部菜单")
  │     → Executor.click_if_exists()
  │       ├── Recognizer.find() → 找到?
  │       ├── AntiDetect.random_offset(cx, cy)
  │       ├── AntiDetect.check_run_limit()
  │       ├── ADBClient.click(cx, cy)
  │       ├── AntiDetect.sleep(base, jitter)
  │       └── AntiDetect.record_action()
  │
  └── return StepResult.success("完成") / StepResult.fail("原因")
```

## 四、事件通信

| 事件 | 发布者 | 订阅者 | 触发时机 |
|------|--------|--------|---------|
| `SCHEDULE_UPDATED` | Scheduler | TaskQueuePanel | 日程表刷新 |
| `TASK_STARTED` | ScriptWorker | TaskQueuePanel | 任务开始执行 |
| `TASK_DONE` | ScriptWorker | TaskQueuePanel | 任务执行完成 |
| `DAILY_RESET` | Scheduler | 模块内部 | 每日00:00 |
| `STATE_CHANGED` | StateManager | UI | 状态变更 |
| `LOG_RECORD` | Monitor | LogPanel | 新日志 |
