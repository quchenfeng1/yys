# 阴阳师自动化识图脚本

基于图像识别的《阴阳师》手游自动化脚本，运行于 PC 端，通过 ADB 连接安卓模拟器。

## 快速开始

### 1. 环境准备

- Python 3.10+
- 模拟器（雷电/MuMu/夜神），分辨率设为 1280×720
- ADB 已安装并在 PATH 中

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 配置模拟器

编辑 `config/global.yaml`，确认 ADB 端口与模拟器一致：
- 雷电: 5555
- MuMu: 7555 或 16384
- 夜神: 62001

### 4. 准备素材图片

将登录流程所需的截图放入「所需图片」文件夹（脚本会自动加载到 assets/ 目录）。

### 5. 运行

```bash
python main.py
```
