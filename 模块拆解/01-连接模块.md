# 01-连接模块（Connection Module）

> **类型**：核心运行层  ｜  **对应说明书**：ADBClient 5.1 + EmulatorManager  ｜  **对应用户模块**：#8 连接模块

---

## 一、目的与作用

**一句话定位**：封装模拟器ADB连接与底层设备操作，对上层完全屏蔽ADB命令细节，统一连接错误的抛出口。

**核心职责**：
1. **连接管理**：建立/断开/检测ADB连接，支持多模拟器多开（每个账号绑定独立端口）
2. **设备操作**：截图、点击、滑动、按键——最底层的"手和眼"
3. **状态监控**：心跳检测连接是否存活，断线时通过事件总线广播
4. **自动重连**：断线后按策略尝试恢复连接
5. **错误出口**：所有连接相关异常（DeviceConnectError等）统一从此模块抛出

**设计原则**：
- 连接模块是**最底层的执行器**，不包含任何业务逻辑
- 截图返回原始图像数据，不做识别（识别归识图模块）
- 点击只接受坐标参数，不做防封号偏移（防封号归安全模块）
- 严格只读模拟器设置，禁止修改模拟器系统配置（用户权限边界）

### 3.2 核心接口设计

```python
class ConnectionManager:
    """连接模块统一入口。管理多设备连接，提供设备操作。"""

    def connect(self, device_id: str = None) -> bool:
        """连接指定设备（device_id如127.0.0.1:16384）。
        未指定则连接配置中的默认设备。"""

    def disconnect(self, device_id: str = None):
        """断开连接"""

    def is_connected(self, device_id: str = None) -> bool:
        """检测连接状态"""

    def get_active_device(self) -> ADBClient:
        """获取当前操作的设备客户端"""

    def switch_device(self, device_id: str) -> bool:
        """切换操作目标设备（多开账号切换时调用）"""

    # === 设备操作（委托给当前ADBClient）===
    def screenshot(self) -> np.ndarray:
        """截图，返回OpenCV格式图像"""

    def click(self, x: int, y: int):
        """坐标点击（仅坐标，不含防封号偏移）"""

    def swipe(self, x1, y1, x2, y2, duration):
        """滑动"""

    def input_key(self, key: str):
        """按键（BACK/HOME/MENU）"""

    def get_screen_size(self) -> tuple:
        """获取屏幕分辨率（只读，不修改）"""

    # === App管理 ===
    def launch_app(self, package: str, activity: str = None) -> bool:
        """启动App（已运行则拉前台）"""

    def is_app_running(self, package: str) -> bool:
        """App是否在运行"""

    def is_app_foreground(self, package: str) -> bool:
        """App是否在前台"""

    # === 状态监控（新增）===
    def start_heartbeat(self, interval: float = 30):
        """启动心跳检测线程"""

    def stop_heartbeat(self):
        """停止心跳"""

    def reconnect(self, device_id: str = None) -> bool:
        """尝试重连（按退避策略重试）"""
```

## 五、关键设计决策

1. **只读模拟器**：严格遵守用户权限边界——只读get_screen_size，禁止wm size/density等写操作
2. **ADB路径自动检测**：保留现有find_adb_path()逻辑，MuMu自带adb优先
3. **截图优化**：`adb exec-out screencap -p`直接输出二进制流，避免文件IO
4. **异常统一出口**：所有连接错误抛 DeviceConnectError，上层统一捕获
5. **心跳退避重连**：断线后1s→2s→4s→8s→16s退避重试，最多5次

### 6.1 连接质量监控

记录截图延迟、命令响应时间，质量差时通过事件总线告警：

```python
class ConnectionQuality:
    """连接质量监控。记录各操作的响应延迟。"""

    def __init__(self):
        self._latency_history: dict[str, list[float]] = {
            "screenshot": [],   # 截图延迟
            "click": [],        # 点击延迟
            "swipe": [],        # 滑动延迟
        }
        self._max_history = 100  # 保留最近100次

    def record(self, operation: str, duration: float):
        """记录操作延迟"""
        self._latency_history[operation].append(duration)
        if len(self._latency_history[operation]) > self._max_history:
            self._latency_history[operation].pop(0)
        # 延迟过高告警
        avg = sum(self._latency_history[operation]) / len(self._latency_history[operation])
        if avg > 2.0:  # 平均延迟超过2秒
            monitor.warning(f"连接质量下降：{operation}平均延迟{avg:.2f}s",
                          module="connection", tags=["quality"])

    def get_quality(self) -> dict:
        """获取连接质量报告"""
        return {
            op: {
                "avg": sum(hist)/len(hist) if hist else 0,
                "max": max(hist) if hist else 0,
                "count": len(hist),
            }
            for op, hist in self._latency_history.items()
        }

class ConnectionManager:
    def screenshot(self) -> np.ndarray:
        start = time.time()
        img = self._adb.screenshot()
        self._quality.record("screenshot", time.time() - start)
        return img

    def click(self, x: int, y: int):
        start = time.time()
        self._adb.click(x, y)
        self._quality.record("click", time.time() - start)
```

### 6.2 连接池预热

多开场景下提前建立连接，账号切换时无需等待：

```python
class ConnectionManager:
    def __init__(self):
        self._device_pool: dict[str, ADBClient] = {}  # device_id → ADBClient
        self._preconnect_list: list[str] = []  # 待预热的设备列表

    def preconnect(self, device_ids: list[str]):
        """预热多个设备连接（多开场景）
        AccountManager初始化时调用，提前建立所有账号的连接。
        """
        for device_id in device_ids:
            if device_id not in self._device_pool:
                threading.Thread(
                    target=self._connect_device, args=(device_id,),
                    daemon=True
                ).start()

    def switch_device(self, device_id: str) -> bool:
        """切换操作目标设备（已预热则瞬间切换）"""
        if device_id in self._device_pool:
            self._active_device = self._device_pool[device_id]
            monitor.info(f"切换设备: {device_id}（已预热）", module="connection")
            return True
        else:
            # 未预热，现场连接
            return self._connect_device(device_id)
```

### 6.3 连接健康度评分

综合多个指标计算连接健康度，低于阈值时主动重连：

```python
class ConnectionHealth:
    """连接健康度评分。综合延迟/成功率/心跳等指标。"""

    def get_score(self) -> float:
        """返回0-100的健康度评分
        90-100: 优秀
        70-89:  良好
        50-69:  一般，建议重连
        <50:    差，必须重连
        """
        score = 100
        # 延迟扣分
        avg_latency = self._quality.get_quality()["screenshot"]["avg"]
        if avg_latency > 1.0:
            score -= min(30, (avg_latency - 1.0) * 20)
        # 心跳失败扣分
        if self._heartbeat_fail_count > 0:
            score -= self._heartbeat_fail_count * 10
        # 操作失败率扣分
        fail_rate = self._get_fail_rate()
        if fail_rate > 0.05:
            score -= min(20, (fail_rate - 0.05) * 100)
        return max(0, score)

    def should_reconnect(self) -> bool:
        """是否建议重连"""
        return self.get_score() < 50
```
