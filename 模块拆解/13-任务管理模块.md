# 13-任务管理模块（Task Manager Module）★v2.4 新增

> **类型**：支撑服务层  ｜  **对应说明书**：5.13  ｜  **说明**：脚本任务的可视化创建/删除/管理

---

## 一、目的与作用

**一句话定位**：脚本任务的生命周期管理器。扫描 tasks/ 目录发现所有游戏任务和通用模块，解析 Python 源码提取元数据（名称/功能描述/分类），提供创建、删除、打开编辑功能。

**与 04-任务模块 的区别**：
- **04-任务模块**：运行时执行任务的引擎（TaskStep / TaskGraph / 通用模块）
- **13-任务管理模块**：开发时的任务文件管理（扫描/创建/删除/打开编辑）

**核心职责**：
1. **任务发现**：扫描 `tasks/daily/`、`tasks/permanent/`、`tasks/event/`、`tasks/special/` 四个目录
2. **通用模块发现**：扫描 `tasks/common/` 目录
3. **元数据解析**：从 Python 文件中提取 `display_name`、`description`、docstring
4. **新建任务**：在指定分类下生成带 docstring 和类属性的 Python 骨架文件
5. **删除任务**：安全删除（重命名为 .deleted 而非物理删除）
6. **打开编辑**：用系统默认程序（VSCode）打开 .py 文件

---

## 二、实现思路

### 2.1 元数据提取规则

从 Python 文件中自动提取以下信息：

```python
"""
每日签到任务
description: 庭院→签到按钮→领取签到奖励
"""

class SignInTask(TaskStep):
    name = "sign_in"
    display_name = "每日签到"
    description = "庭院→签到按钮→领取签到奖励"
```

**提取优先级**：
1. `display_name` 类属性 → 作为显示名
2. `description` 类属性 → 作为功能描述
3. 模块级 docstring 第一行 → fallback 描述

### 2.2 新建任务模板

```python
f'''
"""{display} — {category_label}任务"""

from tasks.base.task_step import TaskStep, StepResult
from tasks.base.task_context import TaskContext

class {ClassName}(TaskStep):
    name = "{name}"
    display_name = "{display}"
    description = "{display}"

    def execute(self, context: TaskContext) -> StepResult:
        return StepResult.success("{display} 完成")
'''
```

### 2.3 核心接口

```python
class TaskManager:
    def scan_all(self)                             # 扫描全部任务和通用模块
    def get_all_tasks(self) -> list[TaskModule]    # 获取全部游戏任务
    def get_tasks_by_category(cat) -> list         # 按分类获取
    def get_generic_modules(self) -> list           # 获取通用模块
    def find_by_name(name) -> TaskModule            # 按文件名查找
    def open_file(module) -> bool                   # 用默认程序打开
    def new_task(category, name, display) -> Path   # 新建任务骨架
    def delete_task(module) -> bool                 # 安全删除
```
