# 03-安全模块（Anti-Detect Module）

> **类型**：核心运行层  ｜  **对应说明书**：AntiDetect 5.4 + 第八部分防封号策略  ｜  **对应用户模块**：#7 安全模块

---

## 一、目的与作用

**一句话定位**：防封号策略引擎，为所有操作（点击/滑动/等待/节奏）生成拟人化随机参数，覆盖全操作链路。

**核心职责**：
1. **点击安全**：随机偏移坐标、贝塞尔曲线鼠标轨迹
2. **滑动安全**：随机滑动时长、起止点微调
3. **等待安全**：随机延迟抖动，避免固定间隔
4. **节奏安全**：走神暂停概率触发，模拟人类注意力波动
5. **上限控制**：每日运行时长/操作次数上限检查
6. **策略可调**：安全强度参数化，可随时调整不影响业务代码

**设计原则**：
- **策略注入而非控制**：安全模块不"控制"识图/执行，而是被Executor调用提供随机参数
- **全链路覆盖**：不只管点击，滑动/等待/节奏都要拟人化
- **参数化**：所有安全参数从配置读取，可热调整
- **可禁用**：调试模式下可关闭安全处理（快速测试）

### 3.2 核心接口设计

```python
class AntiDetect:
    """防封号策略引擎。为所有操作生成拟人化随机参数。"""

    # === 点击安全 ===
    def random_offset(self, cx: int, cy: int, radius: int = 10) -> tuple:
        """在中心点周围生成正态分布随机偏移坐标"""

    def human_move_path(self, x1, y1, x2, y2) -> list[tuple]:
        """生成贝塞尔曲线鼠标移动路径（多段插值，模拟自然移动）"""

    # === 滑动安全 ===
    def random_swipe_duration(self, base: int = 300) -> int:
        """随机滑动时长（base±jitter）"""

    def random_swipe_endpoints(self, x1, y1, x2, y2, jitter: int = 5) -> tuple:
        """滑动起止点微调"""

    # === 等待安全 ===
    def random_delay(self, base: float, jitter: float = 0.5) -> float:
        """生成随机延迟时间"""

    def random_sleep(self, min_s: float = 1.0, max_s: float = 3.0) -> float:
        """随机等待区间"""

    # === 节奏安全 ===
    def maybe_long_pause(self) -> bool:
        """按概率触发长暂停（模拟走神），返回是否触发"""

    def get_pause_duration(self) -> float:
        """走神暂停时长（5-15s随机）"""

    # === 上限控制 ===
    def check_run_limit(self) -> bool:
        """检查是否超出每日运行时长/操作次数上限"""

    def record_operation(self):
        """记录一次操作（用于操作计数）"""

    def get_today_stats(self) -> dict:
        """获取今日运行统计（时长/操作数）"""

    # === 策略切换 ===
    def set_profile(self, profile_name: str):
        """切换行为档案（safe/normal/fast/debug）"""
```

### 3.4 Executor作为注入点

安全策略不硬编码在识图或任务里，而是通过Executor注入：

```python
class Executor:
    """操作执行器。所有操作的统一入口，安全策略在此注入。"""

    def click_image(self, template_name: str, region=None, timeout=10) -> bool:
        # 1. 识图获取原始坐标
        match = self._recognizer.find(template_name, region)
        if not match:
            return False
        # 2. 安全模块加随机偏移
        safe_x, safe_y = self._anti_detect.random_offset(match.center[0], match.center[1])
        # 3. 生成自然移动轨迹
        path = self._anti_detect.human_move_path(self._cursor_pos, (safe_x, safe_y))
        # 4. 走神暂停检查
        if self._anti_detect.maybe_long_pause():
            sleep(self._anti_detect.get_pause_duration())
        # 5. 执行点击
        self._connection.click(safe_x, safe_y)
        # 6. 记录操作
        self._anti_detect.record_operation()
```

## 四、与其他模块的交互

| 交互方 | 方式 | 说明 |
|--------|------|------|
| Executor | 被调用 | Executor在每次操作前调安全模块获取随机参数 |
| 识图模块 | 无直接交互 | 识图返回原始坐标，安全在Executor层注入 |
| 连接模块 | 无直接交互 | 安全参数传给Executor，Executor调连接执行 |
| 定时模块 | 被调用 | 定时模块调check_run_limit()判断是否到上限 |
| 配置模块 | 读配置 | 读取anti_detect段参数 |
| 状态管理 | 读写状态 | 读写今日运行时长/操作次数 |
| 事件总线 | 发布事件 | 超上限时发布run_limit_reached事件 |

## 五、关键设计决策

1. **策略注入模式**：安全模块不"控制"谁，而是被需要安全的操作主动调用
2. **全链路覆盖**：点击/滑动/等待/节奏/上限，缺一不可
3. **行为档案**：safe/normal/fast/debug四档，调试时用debug档快速测试
4. **走神暂停**：概率触发5-15s长暂停，模拟人类注意力波动，是防封关键
5. **上限检查**：每日运行时长（默认8h）+操作次数（默认2000次），到上限强制收尾
6. **操作计数**：每次record_operation()累计，用于上限判断和统计分析

```python
class OperationAudit:
    """操作审计日志。记录每次操作的详细信息。"""

    def record(self, op_type: str, x: int, y: int, *,
               template: str = None, delay_before: float = 0,
               delay_after: float = 0, success: bool = True):
        """记录一次操作
        - op_type: "click"/"swipe"/"long_press"
        - x, y: 操作坐标（安全偏移后的）
        - template: 点击的模板名（如果是click_image）
        - delay_before/after: 操作前后的延迟
        - success: 操作是否成功
        """
        entry = {
            "timestamp": datetime.now().isoformat(),
            "type": op_type,
            "x": x, "y": y,
            "template": template,
            "delay_before": delay_before,
            "delay_after": delay_after,
            "success": success,
            "session_id": self._session_id,
        }
        self._audit_log.append(entry)
        # 写入审计日志文件（JSONL格式）
        monitor.log("DEBUG", f"操作审计: {op_type} ({x},{y})",
                   module="anti_detect", tags=["audit"])

    def export_audit(self, output_path: str, start_time=None, end_time=None):
        """导出审计日志（供行为分析）"""

    def analyze_pattern(self) -> dict:
        """分析操作模式（操作频率/坐标分布/延迟分布），检测是否过于规律"""
```

### 6.2 行为指纹多样性

长时间运行时逐渐变化行为参数（偏移半径/延迟抖动范围），避免行为模式固化被检测：

```python
class BehaviorProfile:
    """行为档案。支持长时间运行时的参数渐变。"""

    # 基础参数
    BASE = {
        "click_offset_radius": 10,
        "delay_jitter": 0.5,
        "long_pause_prob": 0.08,
        "swipe_jitter": 100,
    }

    # 渐变参数：每运行1小时，参数在范围内漂移
    DRIFT = {
        "click_offset_radius": {"min": 8, "max": 14, "rate": 0.5},  # 每小时漂移0.5
        "delay_jitter": {"min": 0.3, "max": 0.8, "rate": 0.05},
        "long_pause_prob": {"min": 0.05, "max": 0.12, "rate": 0.005},
    }

    def update_drift(self, run_duration_hours: float):
        """根据运行时长更新参数（渐变）"""
        for param, config in self.DRIFT.items():
            current = self._current[param]
            # 在[min, max]范围内随机漂移
            drift = random.uniform(-config["rate"], config["rate"])
            new_val = current + drift
            new_val = max(config["min"], min(config["max"], new_val))
            self._current[param] = new_val
            if abs(new_val - current) > 0.01:
                monitor.debug(f"行为参数漂移: {param} {current:.2f}→{new_val:.2f}",
                             module="anti_detect", tags=["drift"])

# 定时更新（每小时一次）
class AntiDetect:
    def start_drift_timer(self):
        """启动行为参数漂移定时器"""
        self._drift_timer = threading.Timer(3600, self._drift_update)
        self._drift_timer.daemon = True
        self._drift_timer.start()

    def _drift_update(self):
        run_hours = (datetime.now() - self._start_time).total_seconds() / 3600
        self._profile.update_drift(run_hours)
        self._drift_timer = threading.Timer(3600, self._drift_update)
        self._drift_timer.daemon = True
        self._drift_timer.start()
```

### 6.4 异常行为检测

检测脚本自身是否出现异常行为模式（如卡在某个位置反复点击），自动中断：

```python
class AntiDetect:
    def __init__(self):
        self._click_history: list[tuple] = []  # (x, y, timestamp)
        self._stuck_threshold = 5  # 同一位置连续点击5次视为卡住

    def check_stuck(self, x: int, y: int) -> bool:
        """检测是否卡在同一位置反复点击"""
        self._click_history.append((x, y, datetime.now()))
        # 只看最近10次点击
        recent = self._click_history[-10:]
        if len(recent) >= self._stuck_threshold:
            # 检查最近N次是否都在同一小范围内
            nearby = sum(1 for (px, py, _) in recent
                        if abs(px - x) < 20 and abs(py - y) < 20)
            if nearby >= self._stuck_threshold:
                monitor.error("检测到卡住行为：同一位置反复点击，可能游戏界面异常",
                             module="anti_detect", tags=["stuck"])
                return True
        return False
```
