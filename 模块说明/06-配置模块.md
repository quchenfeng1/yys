# 06-配置模块（Config Module）

> **类型**：支撑服务层  ｜  **对应说明书**：ConfigManager 5.5  ｜  **对应用户模块**：#5 配置模块

---

## 一、目的与作用

**一句话定位**：配置数据中心。统一加载/管理/持久化所有YAML/JSON配置，提供get/set接口，不涉及运行逻辑判断。

**核心职责**：
1. **配置加载**：启动时加载 global.yaml / tasks.yaml / accounts.yaml / coords/*.json
2. **统一访问**：提供get(key_path) / set(key_path, value) 接口，点分路径访问
3. **持久化**：set后立即写盘（原子写），重启不丢失
4. **热重载**：支持reload()重新读取配置文件（外部修改后同步）
5. **校验**：配置值类型/范围校验，非法值告警

**设计原则**：
- **纯数据，不判断**：配置模块只读写数据，不做"是否允许运行"等业务判断（那归运行控制）
- **单一数据源**：所有模块的配置读取都经此模块，避免各模块自己读文件导致不一致
- **原子持久化**：写临时文件→替换，避免写盘中断损坏

### 3.2 核心接口设计

```python
class ConfigManager:
    """配置数据中心。纯数据读写，不做业务判断。"""

    def get(self, key_path: str, default=None) -> Any:
        """点分路径读取配置值
        例: get("global.adb.port", 5555)
            get("tasks.daily.sign_in.priority", 1)
        """

    def set(self, key_path: str, value: Any):
        """设置配置值并立即持久化
        例: set("global.adb.port", 16384)
        """

    def get_section(self, section: str) -> dict:
        """读取整个配置段
        例: get_section("global.anti_detect") → {click_offset_radius:10, ...}
        """

    def get_coords(self, scene: str) -> dict:
        """读取场景坐标配置 config/coords/{scene}.json"""

    def get_task_config(self, task_name: str) -> dict:
        """读取任务配置（合并tasks.yaml + coords/{name}.json）"""

    def get_team_preset(self, team_id: str) -> dict:
        """读取阵容预设 config/coords/teams/{team_id}.json"""

    def get_account_config(self, account_id: str = None) -> dict:
        """读取账号配置（主号或指定小号）"""

    def reload(self):
        """重新加载所有配置文件（外部修改后同步）"""

    def save(self):
        """将内存配置全部写盘"""

    def validate(self) -> list[str]:
        """校验所有配置，返回错误信息列表"""
```

### 3.3 配置文件体系

```
config/
├── global.yaml              ← 全局配置（adb/screen/app/anti_detect/run/schedule）
├── tasks.yaml               ← 任务编排（default_order + 各任务enabled/priority/repeat）
├── accounts.yaml            ← 账号配置（主号+小号列表）
├── coords/                  ← 场景/任务坐标配置
│   ├── login.json
│   ├── courtyard.json
│   ├── yuhun.json
│   └── teams/
│       ├── yuhun_speed.json
│       └── ...
└── runtime/                 ← 运行时状态（非配置，由定时模块管理）
    └── task_state.json
```

### 3.4 配置访问示例

```python
# 读取ADB端口
port = config.get("global.adb.port", 16384)

# 读取御魂任务配置
yuhun = config.get_task_config("yuhun")
# → {"enabled":true, "priority":10, "repeat":{...}, "times":30, "team_id":"yuhun_speed", ...}

# 修改御魂优先级
config.set("tasks.permanent.yuhun.priority", 5)

# 读取防封号参数
anti = config.get_section("global.anti_detect")

# 读取阵容预设
team = config.get_team_preset("yuhun_speed")
```

## 四、与其他模块的交互

| 交互方 | 方式 | 说明 |
|--------|------|------|
| 所有模块 | 被调用 | 所有需要配置的模块都通过ConfigManager读取 |
| 传参模块 | 双向 | 传参模块的配置数据模型层与配置模块协作 |
| UI模块 | 被调用 | UI修改配置时调set()，显示配置时调get() |
| 定时模块 | 被调用 | 读取tasks.yaml的repeat/priority/enabled |
| 事件总线 | 发布事件 | 配置变更后发布config_changed事件 |

## 五、关键设计决策

1. **纯数据职责**：只读写，不判断"是否允许运行"（那归运行控制模块）
2. **点分路径访问**：`global.adb.port` 形式，统一访问入口
3. **任务配置合并**：get_task_config()合并tasks.yaml（编排）+coords/{name}.json（坐标），一次返回完整配置
4. **原子写盘**：写临时文件→os.replace替换，避免崩溃损坏
5. **热重载**：支持文件监听自动reload，或手动调reload()
6. **校验可选**：validate()返回错误列表，启动时调用，非法配置告警但不阻断

## 六、进一步增强（v2.0）

### 6.1 三级分层覆盖（global → account → task）

支持"全局默认 + 账号定制 + 任务微调"三级配置覆盖，后者覆盖前者：

```
配置优先级（高→低）：
  task级（tasks.permanent.yuhun.anti_detect.click_offset_radius）
  > account级（accounts.main.anti_detect.click_offset_radius）
  > global级（global.anti_detect.click_offset_radius）
```

```python
class ConfigManager:
    def get(self, key_path: str, default=None, *,
            account: str = None, task: str = None) -> Any:
        """三级查找配置值。
        1. 先查task级: tasks.{category}.{task}.{key_path}
        2. 再查account级: accounts.{account}.{key_path}
        3. 最后查global级: global.{key_path}
        4. 都没有则返回default
        """
        # task级覆盖
        if task:
            task_val = self._get_raw(f"tasks.*.{task}.{key_path}")
            if task_val is not None:
                return task_val
        # account级覆盖
        if account:
            acct_val = self._get_raw(f"accounts.{account}.{key_path}")
            if acct_val is not None:
                return acct_val
        # global级默认
        return self._get_raw(f"global.{key_path}", default)

# 使用示例：
# 全局防封号偏移半径=10
# 主号专属偏移半径=12（更保守）
# 御魂任务专属偏移半径=8（刷得快一点）
config.get("anti_detect.click_offset_radius",
            account="main", task="yuhun")  # → 8（task级覆盖）
```

### 6.2 配置版本迁移

配置文件带版本号，升级时自动迁移旧配置格式，兼容历史版本：

```python
class ConfigMigrator:
    """配置版本迁移器。升级时自动迁移旧配置。"""

    CURRENT_VERSION = 2

    MIGRATIONS = {
        # v1→v2: tasks.yaml结构变更（repeat字段合并TimeRule+run_strategy）
        1: "_migrate_v1_to_v2",
        # v2→v3: 新增accounts.yaml多开支持
        2: "_migrate_v2_to_v3",
    }

    def migrate(self, config_data: dict) -> dict:
        """检查版本号，逐步迁移到当前版本"""
        version = config_data.get("_version", 1)
        while version < self.CURRENT_VERSION:
            migrator = getattr(self, self.MIGRATIONS[version])
            config_data = migrator(config_data)
            version += 1
            monitor.info(f"配置已迁移至v{version}", module="config")
        config_data["_version"] = self.CURRENT_VERSION
        return config_data

    def _migrate_v1_to_v2(self, data):
        """v1→v2: 将旧版TimeRule+run_strategy合并为RepeatRule"""
        # ... 迁移逻辑
        return data
```

### 6.3 配置导入导出

支持将全套配置导出为zip备份，或从备份恢复：

```python
class ConfigManager:
    def export_config(self, output_path: str):
        """导出全套配置为zip（global+tasks+accounts+coords+teams）"""
        with zipfile.ZipFile(output_path, 'w') as zf:
            for root, dirs, files in os.walk("config"):
                for f in files:
                    filepath = os.path.join(root, f)
                    zf.write(filepath, filepath)

    def import_config(self, input_path: str, overwrite: bool = False):
        """从zip备份恢复配置。
        - overwrite=False: 只导入不存在的配置文件（不覆盖已有）
        - overwrite=True: 全部覆盖
        """
        # 导入前自动备份当前配置
        self.export_config(f"config_backup_{datetime.now():%Y%m%d%H%M%S}.zip")
        # 解压导入
        with zipfile.ZipFile(input_path, 'r') as zf:
            zf.extractall(".")
        self.reload()
        monitor.info("配置导入完成", module="config")
```

### 6.4 配置变更通知

配置变更时通过事件总线通知相关模块，实现热更新：

```python
class ConfigManager:
    def set(self, key_path: str, value: Any):
        old_value = self._get_raw(key_path)
        self._set_raw(key_path, value)
        self._save()
        # 发布配置变更事件
        event_bus.publish("config_changed",
                         key_path=key_path,
                         old_value=old_value,
                         new_value=value)

# 相关模块订阅配置变更：
class AntiDetect:
    def __init__(self):
        event_bus.subscribe("config_changed",
            handler=self._on_config_changed,
            filter=lambda e: "anti_detect" in e.data.get("key_path", ""))

    def _on_config_changed(self, key_path, old_value, new_value):
        """防封号参数变更时热更新"""
        self._reload_params()
        monitor.info(f"防封号参数热更新: {key_path}", module="anti_detect")
```
