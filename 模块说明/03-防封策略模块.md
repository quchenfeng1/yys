# 03-防封策略模块（Anti-Ban Strategy Module）

> **类型**：核心运行层  ｜  **对应说明书**：AntiDetect 5.4 + 第八部分防封号策略  ｜  **对应用户模块**：#7 安全模块

---

## 一、目的与作用

**一句话定位**：防封号策略引擎，为所有操作（点击/滑动/等待/节奏）生成拟人化随机参数，覆盖全操作链路，模拟人类操作行为。

**核心职责**：
1. **点击安全**：随机偏移坐标、贝塞尔曲线鼠标轨迹，避免固定落点
2. **滑动安全**：随机滑动时长、起止点微调，避免固定滑动模式
3. **等待安全**：随机延迟抖动，避免固定间隔被检测
4. **节奏安全**：走神暂停概率触发，模拟人类注意力波动
5. **策略可调**：安全强度参数化，多档可切换，不影响业务代码

**设计原则**：
- **策略注入而非控制**：被 Executor 调用提供随机参数，不主导执行流程
- **全链路覆盖**：点击/滑动/等待/节奏，缺一不可
- **参数化**：所有安全参数从配置读取，支持热调整
- **可禁用**：调试模式下关闭所有安全处理，便于快速测试

## 三、运行逻辑

### 3.1 安全策略注入流程

安全模块不主动执行任何操作，而是被 Executor 调用提供随机参数：

```
14-执行器模块.click_image(template)
  → 02-图像识别模块.find(template) → 得到原始坐标
  → 03-防封策略模块.random_offset(坐标) → 返回安全偏移后坐标
  → 03-防封策略模块.human_move_path(起点, 终点) → 返回贝塞尔曲线路径点
  → 03-防封策略模块.maybe_long_pause() → 判断是否走神
  → 走神则 03-防封策略模块.get_pause_duration() → 等待随机时长
  → 01-设备连接模块.click(安全坐标) → 执行点击
  → 14-执行器模块 记录结果到 12-日志监控中心
```

### 3.2 随机参数生成规则

| 操作类型 | 随机参数 | 生成策略 |
|---------|---------|---------|
| **点击偏移** | 偏移半径 | 以目标坐标为中心的正态分布随机偏移 |
| **鼠标轨迹** | 路径点列表 | 贝塞尔曲线插值，模拟自然鼠标移动 |
| **滑动时长** | 毫秒数 | 基础时长 ± 随机抖动 |
| **滑动起止** | 坐标微调 | 起止点各加小范围随机偏移 |
| **操作间隔** | 秒数 | 基础延迟 ± 随机抖动，不同场景不同范围 |
| **走神暂停** | 是否触发 + 时长 | 按概率触发，时长5-15s随机 |

### 3.3 行为档案

四档安全强度，可在运行时随时切换：

| 档案 | 偏移半径 | 延迟抖动 | 走神概率 | 适用场景 |
|------|---------|---------|---------|---------|
| **SAFE** | 15px | 1.0s | 15% | 最安全，长时间挂机 |
| **NORMAL** | 10px | 0.5s | 8% | 平衡，日常使用 |
| **FAST** | 5px | 0.2s | 3% | 快速，短期冲刺 |
| **DEBUG** | 0px | 0s | 0% | 调试，关闭所有安全 |

### 3.4 参数渐变（长时间运行）

每运行1小时，行为参数在预设范围内小幅度漂移，避免长时间运行后行为模式固化被检测。偏移半径、延迟抖动、走神概率等参数随时间缓慢变化。

## 四、重点功能

### 4.1 全链路拟人化

覆盖点击、滑动、等待、节奏四个维度，操作间隔随机抖动、鼠标轨迹贝塞尔曲线、走神暂停模拟注意力波动，全方位模拟人类操作特征。

### 4.2 多档行为档案

四档预设 + 支持自定义，不同场景切换不同安全强度。调试时可完全关闭安全处理，不影响开发效率。

### 4.3 操作审计日志

记录每次操作的坐标、时间、类型、延迟等信息，可导出分析。用于事后行为审计和操作模式检测，确保操作足够拟人化。

## 五、实现思路

### 5.1 模块结构

```
core/
├── anti_detect.py       ← AntiDetect 安全策略引擎主入口
└── behavior_profile.py  ← BehaviorProfile 行为档案管理（多档安全强度 + 参数渐变）
```

> ⚠️ **执行器已拆出**：原本文中的 Executor 已拆分为独立的 **14-执行器模块**。本模块只保留策略引擎，安全策略通过 14-执行器模块 的调用注入。

### 5.2 核心方法定义

**AntiDetect（防封策略引擎）**：

| 方法签名 | 可见性 | 所属类 | 作用 |
|---------|--------|--------|------|
| `random_offset(cx, cy, radius) -> tuple` | 🔓 公开 | `AntiDetect` | 在中心点周围生成正态分布随机偏移坐标 |
| `human_move_path(x1,y1,x2,y2) -> list[tuple]` | 🔓 公开 | `AntiDetect` | 生成贝塞尔曲线鼠标移动路径 |
| `random_swipe_duration(base) -> int` | 🔓 公开 | `AntiDetect` | 随机滑动时长（base±jitter） |
| `random_delay(base, jitter) -> float` | 🔓 公开 | `AntiDetect` | 生成随机延迟时间 |
| `random_sleep(min_s, max_s) -> float` | 🔓 公开 | `AntiDetect` | 随机等待区间 |
| `maybe_long_pause() -> bool` | 🔓 公开 | `AntiDetect` | 按概率触发长暂停，返回是否触发 |
| `get_pause_duration() -> float` | 🔓 公开 | `AntiDetect` | 走神暂停时长（5-15s随机） |
| `set_profile(name) -> None` | 🔓 公开 | `AntiDetect` | 切换行为档案（safe/normal/fast/debug） |

**BehaviorProfile（行为档案管理）**：

| 方法签名 | 可见性 | 所属类 | 作用 |
|---------|--------|--------|------|
| `update_drift(run_duration_hours) -> None` | 🔓 公开 | `BehaviorProfile` | 根据运行时长更新参数（渐变） |

### 5.3 核心流程

**安全参数调用流程**（由 14-执行器模块 驱动）：
```
14-执行器模块.click_image("btn")
  → 02-图像识别模块.find() → 得到原始坐标
  → 03-防封策略模块.random_offset(坐标) → 安全偏移
  → 03-防封策略模块.human_move_path() → 轨迹
  → 03-防封策略模块.maybe_long_pause() → 走神判断
  → 14-执行器模块 记录耗时
```

**行为档案切换流程**：
```
set_profile("SAFE")
  → 加载 SAFE 档参数（偏移15px / 抖动1.0s / 走神15%）
  → 更新 _profile_params
  → 后续所有随机参数按新配置生成
```

### 5.4 关键设计

- **策略注入模式**：安全模块不主导执行，而是被调用提供参数，保持各模块职责清晰
- **参数化配置**：所有安全参数从配置读取，可在 UI 面板实时调整
- **全链路覆盖**：点击/滑动/等待/节奏，四个维度缺一不可
- **参数渐变**：长时间运行时参数缓慢漂移，避免行为模式固化
