# 02-识图控制模块（Recognition Module）

> **类型**：核心运行层  ｜  **对应说明书**：Recognizer 5.2  ｜  **对应用户模块**：#6 识图控制模块

---

## 一、目的与作用

**一句话定位**：在截图中定位目标图片，返回匹配位置与置信度。纯识别引擎，不涉及任何操作和安全处理。

**核心职责**：
1. **模板匹配**：在截图中查找目标模板图，返回位置+置信度
2. **素材管理**：加载assets/四层分类目录的全部图片，建立索引
3. **区域限定**：支持限定搜索范围，加速识别减少误匹配
4. **等待机制**：wait/wait_any 轮询等待目标出现
5. **OCR文字定位**：识别界面文字位置（如"进入游戏"），应对动态界面

**设计原则**：
- **纯粹性**：识图模块只做"看"，不做"做"（点击归执行模块，安全归安全模块）
- **无副作用**：识别过程不修改任何状态，纯函数式调用
- **可独立测试**：给图片+模板→返回结果，不依赖设备连接

## 三、实现思路

### 3.1 模块结构

```
core/
├── recognizer.py        ← 识图主引擎（模板匹配）
├── ocr_locator.py       ← OCR文字定位子模块
└── asset_index.py       ← 素材索引管理（新增，从recognizer拆出）
```

### 3.2 核心接口设计

```python
class Recognizer:
    """识图引擎。纯识别，不操作，不防封。"""

    def find(self, template_name: str, region=None, threshold=0.8) -> MatchResult | None:
        """查找单个模板，返回最佳匹配或None"""

    def find_all(self, template_name: str, region=None, threshold=0.8) -> list[MatchResult]:
        """查找所有匹配"""

    def exists(self, template_name: str, threshold=0.8) -> bool:
        """是否存在"""

    def wait(self, template_name: str, timeout=10, interval=0.5) -> MatchResult | None:
        """等待模板出现（轮询截图）"""

    def wait_any(self, template_names: list, timeout=10) -> tuple[str, MatchResult] | None:
        """等待多个模板中任一出现"""

    def reload(self):
        """重新加载素材（素材更新后调用）"""

class OcrLocator:
    """OCR文字定位。用于动态界面（如"进入游戏"按钮位置随背景变化）。"""

    def locate_text(self, text: str, region=None) -> tuple | None:
        """识别文字位置，返回中心坐标(x,y)或None"""

    def locate_any(self, texts: list, region=None) -> tuple[str, tuple] | None:
        """多个候选文字，返回首个匹配"""
```

### 3.3 MatchResult数据结构

```python
@dataclass
class MatchResult:
    name: str          # 模板名
    center: tuple      # 中心坐标 (x, y)
    topleft: tuple     # 左上角坐标
    size: tuple        # 匹配区域大小
    confidence: float  # 置信度 0~1
```

### 3.5 识别策略

- **主用模板匹配**：`cv2.matchTemplate` + `TM_CCOEFF_NORMED`，要求1280×720统一分辨率
- **区域限定**：`region=(x,y,w,h)` 限定搜索范围，加速+减少误匹配
- **灰度优先**：默认转灰度匹配提速，颜色敏感场景可开启彩色
- **OCR兜底**：动态界面（背景变化的按钮）用OCR识别文字位置

## 四、与其他模块的交互

| 交互方 | 方式 | 说明 |
|--------|------|------|
| 连接模块 | 调用 | 调用screenshot()获取当前截图 |
| 安全模块 | 被注入 | Executor在点击前调识图获取坐标，再调安全模块加偏移 |
| 任务模块 | 被调用 | 任务步骤调用find/exists/wait进行识别判断 |
| 配置模块 | 读配置 | 读取识别阈值、素材目录配置 |
| 事件总线 | 无 | 识图是无状态纯操作，不需要事件通信 |

**关键**：识图模块不直接调用安全模块。识图返回原始坐标，安全策略由Executor在中间层注入。

```
任务步骤 → Executor.click_image("btn")
              ├─ 1. Recognizer.find("btn") → 得到原始坐标(637,598)
              ├─ 2. AntiDetect.random_offset(637,598) → 得到安全坐标(641,602)
              └─ 3. Connection.click(641,602) → 执行点击
```

## 五、关键设计决策

1. **保持纯粹**：识图模块不做任何安全处理，保持可独立测试、可独立调优
2. **素材预加载**：启动时全量加载到内存（灰度），避免运行时IO
3. **PIL读取兼容中文路径**：保留现有 `_imread_unicode()` 方案
4. **索引名=相对路径**：`common/battle/challenge_btn` 对应 `assets/common/battle/challenge_btn.png`
5. **OCR作为补充**：静态UI用模板匹配（快），动态界面用OCR（慢但适应变化）

## 六、进一步增强（v2.0）

### 6.1 多尺度匹配

部分场景下模拟器渲染可能有缩放偏差，支持多尺度模板匹配提升鲁棒性：

```python
class Recognizer:
    def find(self, template_name: str, region=None, threshold=0.8,
             multi_scale: bool = False) -> MatchResult | None:
        """查找模板。multi_scale=True时尝试0.95/1.0/1.05三个缩放"""
        if not multi_scale:
            return self._find_single_scale(template_name, region, threshold)
        best = None
        for scale in [0.95, 1.0, 1.05]:
            result = self._find_at_scale(template_name, region, threshold, scale)
            if result and (best is None or result.confidence > best.confidence):
                best = result
        return best
```

### 6.2 识图结果缓存

短时间内对同一模板的重复识别结果缓存，避免重复计算（如等待界面加载时每秒识别一次）：

```python
class Recognizer:
    def __init__(self):
        self._cache: dict[str, tuple[float, MatchResult]] = {}
        self._cache_ttl = 1.0  # 缓存1秒

    def find(self, template_name: str, ...) -> MatchResult | None:
        cached = self._cache.get(template_name)
        if cached and cached[0] > time.time():
            return cached[1]
        result = self._do_find(template_name, region, threshold)
        self._cache[template_name] = (time.time() + self._cache_ttl, result)
        return result
```

### 6.3 识图性能监控

自动记录每次识图的耗时，超过阈值时告警：

```python
class Recognizer:
    def find(self, template_name: str, ...) -> MatchResult | None:
        start = time.time()
        result = self._do_find(template_name, region, threshold)
        duration = time.time() - start
        monitor.record_performance("recognize", duration)
        if duration > 1.0:
            monitor.warning(f"识图耗时过长: {template_name} ({duration:.2f}s)",
                          module="recognizer", tags=["performance"])
        return result
```
