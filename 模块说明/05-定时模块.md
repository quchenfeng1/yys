# 05-定时模块（Scheduler Module）

> **类型**：核心运行层  ｜  **对应说明书**：Scheduler 5.9  ｜  **对应用户模块**：#1 定时模块

---

## 一、目的与作用

**一句话定位**：时间调度引擎。根据每个任务的RepeatRule和next_run_time，决定"何时执行哪个任务"，生成日程表并按优先级调度。

**核心职责**：
1. **时间规则管理**：解析每个任务的RepeatRule（7种类型）
2. **next_run_time机制**：双重判据（now≥next_run_time AND 在window内）
3. **日程表生成**：扫描启用任务→过滤→排序→生成可执行队列
4. **执行推进**：执行成功后按RepeatRule推进next_run_time，失败不推进
5. **状态持久化**：task_state.json原子写盘，重启恢复
6. **次数控制**：times/max_daily/max_total/cooldown/today_count

**设计原则**：
- **纯调度，不管运行控制**：定时模块只回答"下一个该执行什么任务"，不关心"程序是否在运行/暂停"（那归运行控制模块）
- **失败不推进**：mark_done(success=False)不推进next_run_time，保持到期可重试
- **持久化优先**：每次状态变更立即写盘，重启不丢失

## 二、与运行控制模块的职责分离

用户原思路"定时模块前绑定触发开关"。解耦后拆分：

| 职责 | 归属 | 说明 |
|------|------|------|
| 启动/停止/暂停信号接收 | 运行控制模块 | 接收UI按钮信号 |
| 运行允许性检查（防封号上限） | 运行控制模块 | 检查是否允许运行 |
| 调度循环生命周期管理 | 运行控制模块 | 控制循环运行/暂停/停止 |
| **何时执行哪个任务** | **定时模块** | RepeatRule→next_run_time→日程表 |
| **next_run_time推进** | **定时模块** | 执行成功后按规则推进 |
| **日程表生成与排序** | **定时模块** | priority→default_order |
| **次数控制** | **定时模块** | times/max_daily检查 |

### 3.2 核心接口设计

```python
class Scheduler:
    """时间调度引擎。纯调度，不管运行控制。"""

    # === 状态管理 ===
    def load_state(self) -> TaskState:
        """启动时从task_state.json恢复执行记录"""

    def save_state(self):
        """原子写盘（写临时文件→替换）"""

    # === 日程表 ===
    def build_schedule(self, date=None) -> list:
        """扫描启用任务→过滤→排序→生成可执行队列"""

    def get_next_task(self) -> str | None:
        """获取当前应执行的下一个任务名（满足双重判据+未达次数上限）"""

    # === 判断 ===
    def is_due(self, task_name: str, now=None) -> bool:
        """任务是否到期：now≥next_run_time AND (无window或在window内)"""

    def check_times_limit(self, task_name: str) -> bool:
        """是否未达次数上限"""

    # === 推进 ===
    def mark_done(self, task_name: str, success: bool = True):
        """标记完成：success=True按RepeatRule推进next_run_time；False不推进"""

    def update_next_run(self, task_name: str, next_run_time: datetime):
        """手动设置next_run_time（UI修改/跳过本次时调用）"""

    def report_expire(self, task_name: str, expire_at: datetime):
        """任务上报外部失效时间（结界卡等）"""

    # === 查询 ===
    def get_next_run_time(self, task_name: str) -> datetime:
        """读取next_run_time（供UI展示倒计时）"""

    def get_task_status(self, task_name: str) -> str:
        """任务状态：待执行/等待中/已完成/已跳过"""

    # === 注册 ===
    def register_task(self, name: str, repeat: RepeatRule, priority: int, **kw):
        """注册任务到调度器（自动注册时调用）"""

    # === 重置 ===
    def reset_daily_counters(self):
        """每日00:00重置today_count=0"""
```

### 3.3 RepeatRule七种类型

```python
class RepeatRule:
    type: str            # once/daily/weekly/monthly/interval_days/interval_hours/expire_at
    at_time: str = None  # "HH:MM"
    weekdays: list = None    # [1,3,5]
    month_days: list = None  # [1,15]
    days: int = None         # interval_days
    hours: float = None      # interval_hours
    at: str = None           # once完整时间
    times: int = 1           # 单次调度执行次数
    window: dict = None      # 可选时间窗口
```

### 3.4 双重判据与推进规则

```
可执行 = (now ≥ next_run_time) AND (window为空 OR now在window内)

执行成功后推进next_run_time：
  once          → 标记completed，不再调度
  daily         → 次日at_time
  weekly        → 下个匹配weekdays的at_time
  monthly       → 下个匹配month_days的at_time
  interval_days → 今日+days天的at_time
  interval_hours→ now+hours
  expire_at     → 不自动推进，等任务上报report_expire()
```

### 3.5 调度循环（由运行控制模块驱动）

```python
# 定时模块提供get_next_task()，ScriptWorker驱动循环：
class ScriptWorker:
    def _run_schedule_loop(self):
        """持续调度循环：Scheduler 驱动，不断检查并执行到期任务。"""
        while not self.is_stopped():
            # 1. 刷新日程表 → 发布到 UI
            schedule = self.scheduler.build_schedule()
            
            # 2. 获取下一个到期任务
            task_name = self.scheduler.get_next_task()
            if not task_name:
                sleep(5)  # 无任务，休眠
                continue
            
            # 3. 执行任务（动态导入 + 创建 TaskContext）
            event_bus.publish("task_started", task_name=task_name)
            success = self._execute_scheduled_task(task_name)
            
            # 4. 标记完成（推进 next_run_time 或保持）
            self.scheduler.mark_done(task_name, success=success)
            event_bus.publish("task_done", task_name=task_name, success=success)
```

## 五、关键设计决策

1. **纯调度职责**：不管运行态（暂停/停止），只管"下一个执行谁"，与运行控制解耦
2. **next_run_time核心判据**：解决"做过不再重复做"，重启不丢失
3. **失败不推进**：临时失败不会跳过每日任务，保持到期可重试
4. **双重判据**：next_run_time + window，精确控制"何时可做"+"何时段允许"
5. **原子持久化**：写临时文件→替换，避免崩溃损坏
6. **每日重置00:00**：阴阳师游戏重置时间，reset_daily_counters重置today_count
7. **小号任务过滤**：AccountManager.get_task_scope()过滤，小号只产出permanent类

## 六、进一步增强（v2.0）

### 6.1 调度可视化

通过事件总线发布日程表更新，UI实时展示任务队列和执行顺序：

```python
class Scheduler:
    def build_schedule(self, date=None) -> list:
        queue = self._do_build(date)
        # 发布日程更新事件，UI订阅后展示任务队列
        event_bus.publish("schedule_updated", queue=[
            {"task": t.name, "next_run": t.next_run_time.isoformat(),
             "priority": t.priority, "status": t.status}
            for t in queue
        ])
        return queue
```

### 6.2 任务冲突检测

同一时段有多个任务到期时，按优先级排序并提示用户：

```python
class Scheduler:
    def get_next_task(self) -> str | None:
        due_tasks = [t for t in self._tasks if self.is_due(t.name)]
        if len(due_tasks) > 1:
            # 多任务同时到期，按优先级排序
            due_tasks.sort(key=lambda t: t.priority, reverse=True)
            monitor.info(f"多任务同时到期({len(due_tasks)}个)，按优先级执行: "
                        f"{' → '.join(t.name for t in due_tasks)}",
                        module="scheduler", tags=["conflict"])
        return due_tasks[0].name if due_tasks else None
```

### 6.3 调度性能优化

大量任务时避免每次全量扫描，维护到期任务的最小堆：

```python
import heapq

class Scheduler:
    def __init__(self):
        self._due_heap: list = []  # 最小堆: (next_run_time, task_name)

    def _rebuild_heap(self):
        """重建到期堆（任务注册/修改next_run_time时调用）"""
        self._due_heap = []
        for name, task in self._tasks.items():
            if task.enabled and task.next_run_time:
                heapq.heappush(self._due_heap, (task.next_run_time, name))

    def get_next_task(self) -> str | None:
        """O(log n)获取下一个到期任务，而非O(n)全量扫描"""
        while self._due_heap:
            next_time, name = heapq.heappop(self._due_heap)
            task = self._tasks.get(name)
            if not task or not task.enabled:
                continue
            if not self.is_due(name):
                # 未到期，放回堆
                heapq.heappush(self._due_heap, (next_time, name))
                return None
            if not self.check_times_limit(name):
                continue
            return name
        return None
```
