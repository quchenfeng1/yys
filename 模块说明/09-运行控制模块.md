# 09-运行控制模块（Run Controller Module）★v2.2 强制停止版

> **类型**：支撑服务层  ｜  **对应说明书**：5.9（新概念，从定时模块拆出）  ｜  **对应用户模块**：从#1定时模块拆出

## 一、目的与作用

**一句话定位**：程序运行生命周期管理。接收UI启停信号，检查运行允许性，驱动调度循环。**v2.1：停止 = 立即强制终止，不等待。**

**v2.1 核心变更**：
- **停止行为**：点击停止按钮 → 立即中断所有线程 → 强制终止 → 发布 run_stopped。不等、不优雅、瞬间生效。
- **实现方式**：`threading.Event` 检查 + Windows `TerminateThread` API 兜底。
- **任务隔离**：每个任务在独立线程执行，便于精确终止。

拆分后：
- **定时模块**：纯调度——给定运行态，下一个该执行什么任务
- **运行控制模块**：生命周期——接收信号、检查允许性、驱动循环、协调收尾

**核心职责**：
1. **信号接收**：接收UI的start/stop/pause信号（通过事件总线）
2. **允许性检查**：检查防封号上限、配置允许、连接状态
3. **调度循环驱动**：运行态下循环调Scheduler.get_next_task()执行
4. **★强制停止（v2.1）**：停止按钮立即中断所有线程，不等待当前步骤完成
5. **暂停恢复**：暂停时暂停调度循环，恢复后继续

**设计原则**：
- **状态机驱动**：running/paused/stopped，状态转换明确
- **★强制停止（v2.1）**：停止 = 立即终止，不等步骤完成。使用 threading.Event + TerminateThread API
- **任务线程隔离**：每个任务在独立线程执行，便于精确终止

## 二、运行状态机

```
                    start_requested
    stopped ──────────────────────► running
       ▲                               │
       │                               │ pause_requested
       │          stop_requested       ▼
       │◄────────────────────────  paused
       │  (立即强制终止)               │
       │                              │ start_requested（恢复）
       │                              ▼
       │                           running
       │
       └──── 任意状态 stop_requested → force_stop() → stopped
```

> v2.1：从任意非 stopped 状态点击停止 → 立即调用 force_stop() → 强制终止所有线程 → stopped。无 stopping 中间态。

### 3.2 核心接口设计

```python
class RunState(Enum):
    STOPPED = "stopped"
    RUNNING = "running"
    PAUSED = "paused"

class RunController:
    """程序运行生命周期管理（v2.1 强制停止版）。"""

    def __init__(self, scheduler, connection, config, state_manager):
        self._stop_event = threading.Event()       # ★ v2.1 强制停止信号
        self._task_stop_event = threading.Event()  # ★ v2.1 任务级停止信号
        self._task_thread: threading.Thread = None  # ★ v2.1 任务独立线程
        ...

    def _on_stop(self):
        """★ v2.1：立即强制终止。"""
        self.force_stop()

    def force_stop(self):
        """立即强制终止所有线程。"""
        self._stop_event.set()
        self._task_stop_event.set()
        if self._task_thread and self._task_thread.is_alive():
            self._force_kill_thread(self._task_thread)  # TerminateThread API
        if self._run_thread and self._run_thread.is_alive():
            self._force_kill_thread(self._run_thread)
        self._cleanup_after_stop()


    def _on_pause(self):
        if self._state == RunState.RUNNING:
            self._state = RunState.PAUSED
            state_manager.set_state(StateKeys.RUN_STATUS, "paused")
            event_bus.publish(Events.RUN_PAUSED)

    def _start_run(self):
        """启动运行"""
        # 1. 允许性检查
        if not self._check_run_allowed():
            return
        # 2. 初始化连接
        if not self._connection.is_connected():
            self._connection.connect()
        # 3. 加载调度状态
        self._scheduler.load_state()
        # 4. 启动工作线程
        self._state = RunState.RUNNING
        state_manager.set_state(StateKeys.RUN_STATUS, "running")
        state_manager.set_state(StateKeys.RUN_START_TIME, datetime.now())
        event_bus.publish(Events.RUN_STARTED, start_time=datetime.now())
        self._run_thread = Thread(target=self._run_loop, daemon=True)
        self._run_thread.start()

    def _run_loop(self):
        """主调度循环"""
        while self._state in (RunState.RUNNING, RunState.STOPPING):
            if self._state == RunState.PAUSED:
                sleep(0.5)
                continue
            # 1. 检查运行允许性（防封号上限等）
            if not self._check_run_allowed():
                break
            # 2. 优雅停止检查
            if self._state == RunState.STOPPING:
                # 等当前任务完成（如果有）
                if self._current_task is None:
                    break
                continue
            # 3. 获取下一个到期任务
            task_name = self._scheduler.get_next_task()
            if not task_name:
                sleep(10)  # 无任务，等待
                continue
            # 4. 执行任务
            self._current_task = task_name
            state_manager.set_state(StateKeys.CURRENT_TASK, task_name)
            event_bus.publish(Events.TASK_STARTED, task_name=task_name)
            success = self._execute_task(task_name)
            # 5. 标记完成
            self._scheduler.mark_done(task_name, success=success)
            event_bus.publish(Events.TASK_DONE, task_name=task_name, success=success)
            self._current_task = None
            state_manager.set_state(StateKeys.CURRENT_TASK, None)

        # 循环结束，收尾
        self._cleanup()

    def _check_run_allowed(self) -> bool:
        """运行允许性检查"""
        # 1. 防封号上限
        if anti_detect.check_run_limit():
            event_bus.publish(Events.RUN_LIMIT_REACHED)
            return False
        # 2. 连接状态
        if not connection.is_connected():
            return False
        return True

    def _execute_task(self, task_name: str) -> bool:
        """执行单个任务"""
        task = task_registry.get(task_name)
        if not task:
            return False
        try:
            return task.execute()
        except Exception as e:
            logger.error(f"任务执行异常: {task_name} - {e}")
            return False

    def _cleanup(self):
        """收尾：保存状态、断开连接"""
        self._scheduler.save_state()
        self._state = RunState.STOPPED
        state_manager.set_state(StateKeys.RUN_STATUS, "stopped")
        event_bus.publish(Events.RUN_STOPPED)
```

### 3.3 优雅停止机制

```python
def _on_stop(self):
    """用户点停止时不立即中断，等当前步骤完成"""
    self._state = RunState.STOPPING
    # 主循环检测到STOPPING后，等current_task变None再退出
    # 当前任务的当前步骤会执行完（步骤是原子单位，不可中途打断）
    # 步骤完成后，循环退出，走_cleanup收尾
```

## 五、关键设计决策

1. **从定时模块拆出**：运行生命周期管理与时间调度是正交职责，拆分后各自清晰
2. **状态机驱动**：stopped→running→paused→stopping→stopped，转换明确可控
3. **优雅停止**：STOPPING状态等当前步骤完成再退出，步骤是原子单位不可中断
4. **允许性检查**：每轮循环前检查防封号上限+连接状态，不满足则停止
5. **工作线程**：调度循环在独立daemon线程，不阻塞UI线程
6. **收尾保障**：无论正常停止还是异常，都走_cleanup保存状态
7. **暂停记忆**：暂停时current_task保留，恢复时继续执行（不重新调度）

### 6.1 异常恢复策略

针对不同类型的异常，采取不同的恢复策略：

```python
class RecoveryStrategy:
    """异常恢复策略。根据异常类型选择恢复路径。"""

    STRATEGIES = {
        "connection_lost": "pause_reconnect",    # 连接断开→暂停+重连
        "recognize_fail": "retry_3_times",       # 识图失败→重试3次
        "operation_timeout": "retry_2_times",    # 操作超时→重试2次
        "task_exception": "return_hall_continue", # 任务异常→返回大厅后继续调度
        "unknown_error": "stop_script",          # 未知错误→停止脚本
    }

class RunController:
    def _execute_task(self, task_name: str) -> bool:
        """执行任务，含异常恢复逻辑"""
        task = task_registry.get(task_name)
        try:
            return task.execute()
        except ConnectionError as e:
            # 连接异常→暂停+重连
            monitor.capture_on_error(task_name, "connection", e)
            return self._handle_connection_error(task_name, e)
        except RecognizeError as e:
            # 识图失败→重试
            monitor.capture_on_error(task_name, "recognize", e)
            return self._handle_recognize_error(task_name, e)
        except TaskTimeoutError as e:
            # 超时→重试
            monitor.capture_on_error(task_name, "timeout", e)
            return self._handle_timeout(task_name, e)
        except Exception as e:
            # 未知异常→记录+返回大厅
            monitor.capture_on_error(task_name, "unknown", e)
            return self._handle_unknown_error(task_name, e)

    def _handle_connection_error(self, task_name, error) -> bool:
        """连接异常恢复：暂停调度→重连→恢复"""
        monitor.warning(f"任务{task_name}连接异常，暂停重连", task=task_name)
        state_manager.set_state(StateKeys.RUN_STATUS, "paused")
        if connection.reconnect():
            monitor.info("重连成功，恢复调度", task=task_name)
            state_manager.set_state(StateKeys.RUN_STATUS, "running")
            return False  # 本次失败，下次重试
        else:
            monitor.error("重连失败，停止脚本", task=task_name)
            self._state = RunState.ERROR
            return False

    def _handle_recognize_error(self, task_name, error) -> bool:
        """识图失败恢复：重试3次，仍失败则返回大厅"""
        for attempt in range(3):
            monitor.info(f"识图失败，重试({attempt+1}/3)", task=task_name)
            sleep(anti_detect.random_delay(3))
            task = task_registry.get(task_name)
            try:
                return task.execute()
            except RecognizeError:
                continue
        # 3次都失败→返回大厅
        monitor.warning(f"识图3次失败，返回大厅跳过任务", task=task_name)
        executor.click_image("common/nav/back_btn")
        return False
```

### 6.2 熔断机制

连续失败超过阈值时自动停止，避免死循环浪费操作次数：

```python
class CircuitBreaker:
    """熔断器。连续失败超过阈值时自动停止。"""

    def __init__(self, threshold: int = 5, reset_after: float = 300):
        self._threshold = threshold       # 连续失败5次触发熔断
        self._reset_after = reset_after   # 熔断后5分钟自动恢复
        self._fail_count = 0
        self._last_fail_time = None
        self._tripped = False

    def record_success(self):
        """记录一次成功（重置计数）"""
        self._fail_count = 0
        if self._tripped:
            monitor.info("熔断器恢复", module="run_controller", tags=["circuit"])
            self._tripped = False

    def record_fail(self) -> bool:
        """记录一次失败，返回是否触发熔断"""
        self._fail_count += 1
        self._last_fail_time = datetime.now()
        if self._fail_count >= self._threshold and not self._tripped:
            self._tripped = True
            monitor.error(f"连续失败{self._fail_count}次，触发熔断！",
                         module="run_controller", tags=["circuit"])
            event_bus.publish("circuit_breaker_tripped",
                            fail_count=self._fail_count)
            return True
        return False

    def is_tripped(self) -> bool:
        """是否处于熔断状态"""
        if self._tripped:
            # 检查是否到了恢复时间
            if (datetime.now() - self._last_fail_time).total_seconds() > self._reset_after:
                self._tripped = False
                self._fail_count = 0
                monitor.info("熔断器自动恢复（超时重置）",
                           module="run_controller", tags=["circuit"])
                return False
            return True
        return False

class RunController:
    def __init__(self, ...):
        self._breaker = CircuitBreaker(threshold=5)

    def _run_loop(self):
        while self._state in (RunState.RUNNING, RunState.STOPPING):
            # 熔断检查
            if self._breaker.is_tripped():
                monitor.warning("熔断状态，暂停调度60秒", module="run_controller")
                sleep(60)
                continue
            # ... 正常调度
            success = self._execute_task(task_name)
            if success:
                self._breaker.record_success()
            else:
                if self._breaker.record_fail():
                    # 熔断触发→停止运行
                    self._state = RunState.ERROR
                    state_manager.set_state(StateKeys.RUN_STATUS, "error")
                    break
```

### 6.3 任务依赖感知

某些任务存在依赖关系（如"悬赏封印"依赖"每日签到"先完成），调度时感知依赖：

```python
class RunController:
    def _get_next_runnable_task(self) -> str | None:
        """获取下一个可运行任务（考虑依赖）"""
        while True:
            task_name = scheduler.get_next_task()
            if not task_name:
                return None
            task = task_registry.get(task_name)
            # 检查依赖
            if task.depends_on:
                for dep in task.depends_on:
                    if not scheduler.is_completed_today(dep):
                        monitor.info(f"任务{task_name}依赖{dep}未完成，跳过",
                                   task=task_name, tags=["dependency"])
                        scheduler.skip_this_round(task_name)
                        continue  # 查下一个任务
            return task_name
```
