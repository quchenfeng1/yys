## 一、系统启动时序

```mermaid
sequenceDiagram
    participant BAT as 启动.bat
    participant MAIN as main.py
    participant BOOT as Bootstrap<br/>(16-应用启动引导)
    participant CM as ConfigManager<br/>(06-配置管理中心)
    participant EB as EventBus<br/>(08-事件通信)
    participant MON as Monitor<br/>(12-日志监控中心)
    participant SM as StateManager<br/>(07-运行时状态管理)
    participant CONN as ConnectionManager<br/>(01-设备连接模块)
    participant REC as Recognizer<br/>(02-图像识别)
    participant AD as AntiDetect<br/>(03-防封策略)
    participant SCH as Scheduler<br/>(05-时间调度模块)
    participant EXE as Executor<br/>(14-执行器)
    participant REG as TaskRegistry<br/>(04-任务执行引擎)
    participant TKM as TaskManager<br/>(13-任务文件管理)
    participant PB as ParamBridge<br/>(10-参数桥接模块)
    participant AM as AccountManager<br/>(15-账号管理模块)
    participant RC as RunController<br/>(09-运行控制中心)
    participant MW as MainWindow<br/>(11-用户界面)

    BAT->>MAIN: pythonw 启动
    MAIN->>MAIN: 创建 QApplication
    MAIN->>BOOT: bootstrap.start()
    
    activate BOOT
    Note over BOOT: === 第1层：基础设施 ===
    BOOT->>CM: ConfigManager()
    CM-->>BOOT: 加载 global.yaml / tasks.yaml / accounts.yaml
    BOOT->>EB: EventBus(全局单例)
    EB-->>BOOT: 启动 dispatch_thread
    
    Note over BOOT: === 第2层：基础服务 ===
    BOOT->>MON: Monitor(config, event_bus)
    BOOT->>SM: StateManager(event_bus)
    SM-->>BOOT: run_status=stopped
    
    Note over BOOT: === 第3层：核心功能 ===
    BOOT->>CONN: ConnectionManager(config, event_bus, state_manager)
    BOOT->>REC: Recognizer(connection, config, monitor, event_bus)
    REC->>REC: 扫描 assets/ → 加载素材索引
    BOOT->>AD: AntiDetect(config, monitor, event_bus)
    
    Note over BOOT: === 第4层：业务编排 ===
    BOOT->>SCH: Scheduler(config, state_manager, event_bus)
    SCH->>SCH: load_tasks_from_config() + load_state()
    BOOT->>EXE: Executor(recognizer, anti_detect, connection, monitor, config)
    BOOT->>REG: 扫描 tasks/ → 注册全部任务
    BOOT->>TKM: TaskManager()
    BOOT->>PB: ParamBridge(config, state_manager, event_bus, scheduler)
    
    Note over BOOT: === 第5层：账号管理 ===
    BOOT->>AM: AccountManager(config, connection, state_manager, event_bus, scheduler)
    
    Note over BOOT: === 第6层：运行控制 ===
    BOOT->>RC: RunController(scheduler, registry, connection, config, state_manager, event_bus, monitor, executor, recognizer, anti_detect, account_manager)
    
    Note over BOOT: === 第7层：用户界面 ===
    BOOT->>MW: MainWindow(param_bridge, event_bus, image_manager)
    MW->>MW: init_ui() → 三栏布局
    MW->>MW: ParamBridge.bind_all()
    BOOT->>BOOT: self_check() → 发布 preflight_complete
    BOOT->>EB: publish(app_started)
    deactivate BOOT
    
    MAIN->>MAIN: app.exec_() — Qt 事件循环
```

## 三、运行启动 → 执行循环（核心）

```mermaid
sequenceDiagram
    participant USER as 用户
    participant MW as MainWindow<br/>(11-用户界面)
    participant PB as ParamBridge<br/>(10-参数桥接)
    participant EB as EventBus<br/>(08-事件通信)
    participant RC as RunController<br/>(09-运行控制中心)
    participant CONN as ConnectionManager<br/>(01-设备连接)
    participant SCH as Scheduler<br/>(05-时间调度)
    participant SM as StateManager<br/>(07-运行时状态管理)
    participant MON as Monitor<br/>(12-日志监控)
    participant EXE as Executor<br/>(14-执行器)
    participant REC as Recognizer<br/>(02-图像识别)
    participant AD as AntiDetect<br/>(03-防封策略)
    participant TASK as BaseTask子类<br/>(04-任务执行引擎)
    participant LF as LoginFlow
    participant ADB as ADBClient

    USER->>MW: 点击「启动」
    MW->>PB: RunBridge.request_start()
    PB->>EB: publish(start_requested)
    EB->>RC: 分发 start_requested
    
    activate RC
    Note over RC: === _on_start() ===
    
    Note over RC: === Step1: 允许性检查 ===
    RC->>RC: get_current() → 获取当前账号
    RC->>RC: config.get() → 读取上限配置
    RC->>CONN: is_connected()
    CONN-->>RC: True
    
    Note over RC: === Step2: 连接设备 ===
    RC->>CONN: connect(device_id)
    CONN->>ADB: connect serial
    ADB-->>CONN: 连接成功
    CONN-->>RC: True
    CONN->>SM: set_state(connection_status=connected)
    
    Note over RC: === Step3: 加载调度状态 ===
    RC->>SCH: load_state()
    SCH-->>RC: 调度状态已恢复
    
    Note over RC: === Step4: 初始化队列 ===
    RC->>RC: 创建空 FIFO 队列 _task_queue
    
    Note over RC: === Step5: 状态置为 running ===
    RC->>SM: set_state(run_status=running)
    
    Note over RC: === Step6-7: 启动线程 ===
    RC->>RC: 启动_filler_loop() + _executor_loop()
    
    RC->>EB: publish(run_started)
    EB->>MW: 更新状态栏
    
    Note over RC: === 填充线程循环 ===
    loop filler_loop (每2~3秒)
        RC->>SCH: get_next_task()
        SCH->>SCH: build_schedule() → 到期任务
        SCH-->>RC: 任务名 or None
        alt 有到期任务
            RC->>RC: 入队 _task_queue
            RC->>EB: publish(schedule_updated)
            EB->>MW: TaskQueuePanel 刷新
        else 无任务
            RC->>RC: adaptive_delay()
        end
    end
    
    Note over RC: === 执行线程循环 ===
    loop executor_loop
        RC->>RC: _task_queue 出队
        RC->>EB: publish(task_started)
        EB->>MW: 更新当前任务卡片
        
        RC->>TASK: task.execute(context)
        activate TASK
        TASK->>EXE: click_image/challenge_btn
        EXE->>REC: find(challenge_btn)
        REC->>CONN: screenshot()
        CONN-->>REC: np.ndarray
        REC-->>EXE: MatchResult
        EXE->>AD: random_offset_in_bounds()
        AD-->>EXE: (safe_x, safe_y)
        EXE->>AD: sleep()
        EXE->>CONN: click(safe_x, safe_y)
        EXE->>AD: record_action()
        TASK-->>RC: StepResult
        deactivate TASK
        
        RC->>SCH: mark_done(name, success)
        RC->>MON: record_task_done(name, success, duration)
        RC->>EB: publish(task_done)
        EB->>MW: 清除当前任务卡片
    end
    
    deactivate RC
```

## 四、调度循环时序（核心）

```mermaid
sequenceDiagram
    participant SW as ScriptWorker<br/>(09-运行控制中心)
    participant SCH as Scheduler<br/>(05-时间调度模块)
    participant EB as EventBus
    participant UI as TaskQueuePanel<br/>(11-用户界面)
    participant FS as 文件系统
    participant TASK as TaskStep 子类<br/>(04-任务执行引擎)
    participant CTX as TaskContext
    participant EXE as Executor<br/>(14-执行器)

    loop while not is_stopped()
        SW->>SCH: build_schedule()
        SCH->>SCH: 遍历所有启用任务 → is_due() + check_times_limit()
        SCH->>SCH: 按 priority 升序排序
        SCH->>EB: publish(SCHEDULE_UPDATED)
        EB->>UI: 刷新任务队列卡片
        
        SW->>SCH: get_next_task()
        alt 无到期任务
            SCH-->>SW: None
            SW->>SW: sleep(5)
        else 有到期任务
            SCH-->>SW: "soul_10"
            
            SW->>EB: publish(TASK_STARTED, task_name="soul_10")
            EB->>UI: 高亮当前任务, 显示进度
            
            SW->>SW: TaskRegistry.get("soul_10") → 新任务实例
            
            SW->>CTX: TaskContext(task_name, task_config, executor, recognizer, log)
            SW->>TASK: step.execute(context)
            
            activate TASK
            Note over TASK,EXE: 任务内部执行 (详见 §五)
            TASK-->>SW: StepResult(status="success")
            deactivate TASK
            
            SW->>SCH: mark_done("soul_10", success=True)
            SCH->>SCH: 推进 next_run_time (按 repeat 规则)
            SCH->>SCH: fail_streak 归零
            SCH->>SCH: save_state() — 原子写盘
            
            SW->>EB: publish(TASK_DONE, task_name="soul_10", success=True)
            EB->>UI: 清除当前任务卡片, 刷新队列
        end
        
        SW->>SW: 检查 is_stopped()
    end
```

## 五、任务执行内部时序（TaskStep → Executor 全链路）

```mermaid
sequenceDiagram
    participant SW as ScriptWorker
    participant CTX as TaskContext
    participant GRAPH as TaskGraph<br/>(04-任务执行引擎)
    participant STEP as 特化步骤<br/>(EnterDungeon)
    participant GEN as 通用模块<br/>(BattleLoop)
    participant EXE as Executor<br/>(14-执行器)
    participant REC as Recognizer<br/>(02-图像识别)
    participant AD as AntiDetect<br/>(03-防封策略)
    participant ADB as ADBClient<br/>(01-设备连接模块)
    participant EB as EventBus

    SW->>CTX: TaskContext(task_name, task_config, executor, recognizer, log)
    SW->>GRAPH: build_graph(context).run(context)
    
    activate GRAPH
    Note over GRAPH: === SETUP 阶段 ===
    
    GRAPH->>STEP: ClosePopup.execute(context)
    STEP->>EXE: click_if_exists("common/ui/close_btn")
    EXE->>REC: find("common/ui/close_btn")
    REC->>ADB: screenshot()
    ADB-->>REC: np.ndarray
    REC->>REC: cv2.matchTemplate()
    REC-->>EXE: MatchResult(center=(200,300), confidence=0.92)
    EXE->>AD: random_offset(200, 300)
    AD-->>EXE: (203, 297)
    EXE->>AD: check_run_limit()
    EXE->>ADB: click(203, 297)
    EXE->>AD: sleep(0.8, 0.5)
    EXE->>AD: record_action()
    EXE-->>STEP: True
    STEP-->>GRAPH: StepResult.success("关闭 1 个弹窗")
    
    GRAPH->>STEP: EnterDungeon.execute(context)
    STEP->>EXE: click_image("副本/按钮-八岐大蛇", timeout=5)
    Note over EXE,ADB: ...识图→偏移→点击 全链路...
    EXE-->>STEP: True
    STEP->>EXE: click_image("副本/按钮-第十层", timeout=3)
    EXE-->>STEP: True
    STEP-->>GRAPH: StepResult.success("已进入副本第10层")
    
    Note over GRAPH: === LOOP 阶段 (BattleLoop 内部循环 N 次) ===
    
    GRAPH->>GEN: BattleLoop(times=3).execute(context)
    activate GEN
    loop i = 0..2
        GEN->>REC: wait_any(["common/battle/victory", "common/battle/defeat"], timeout=180)
        REC->>ADB: screenshot() (轮询)
        REC-->>GEN: ("common/battle/victory", MatchResult)
        GEN->>EXE: click_if_exists("common/battle/confirm_btn")
        Note over EXE,ADB: 识图→偏移→点击 结算按钮
        EXE-->>GEN: True
        GEN->>EXE: random_sleep(1, 2)
    end
    GEN-->>GRAPH: StepResult.success("完成 3 轮战斗")
    deactivate GEN
    
    Note over GRAPH: === TEARDOWN 阶段 ===
    
    GRAPH->>STEP: ReturnHall.execute(context)
    STEP->>EXE: click_if_exists("common/ui/back_btn")
    STEP->>REC: exists("scenes/courtyard/main")
    Note over STEP,REC: 反复返回直到识别到庭院
    
    alt 任一步骤失败
        GRAPH->>STEP: ErrorReturn (错误分支)
        STEP-->>GRAPH: StepResult.skip("任务跳过")
    end
    
    GRAPH-->>SW: True (全部成功)
    deactivate GRAPH
    
    SW->>EB: publish(TASK_DONE, task_name="soul_10", success=True)
```

## 六、用户停止时序

```mermaid
sequenceDiagram
    participant USER as 用户
    participant MW as MainWindow
    participant SW as ScriptWorker<br/>(09-运行控制中心)
    participant STEP as 当前步骤<br/>(04-任务执行引擎)

    SM->>EB: publish(state_changed)
    EB->>UI: ControlBar 恢复按钮状态
    EB->>UI: StatusBar 显示「待机」
```

## 九、模块间调用关系速查

```
调用层级 (上→下):

11-用户界面 ─── 直接持有 ──→ 06-配置管理
    │                       13-任务文件管理
    │                       素材管理
    │                       05-时间调度
    │
    └── 创建并启动 ──→ 09-运行控制 (ScriptWorker QThread)
                          │
                          ├──→ 05-时间调度 (Scheduler)
                          ├──→ 01-设备连接 (EmulatorManager / ADBClient)
                          ├──→ 02-图像识别 (Recognizer)
                          ├──→ 03-防封策略 (AntiDetect)
                          ├──→ 14-执行器 (Executor)
                          │      ├──→ 02-图像识别
                          │      ├──→ 03-防封策略
                          │      └──→ 01-设备连接
                          ├──→ 04-任务执行引擎 (动态 import → execute)
                          │      ├──→ 14-执行器 (通过 context.executor)
                          │      └──→ 02-图像识别 (通过 context.recognizer)
                          └──→ tasks/login_flow.py (LoginFlow)

08-事件通信总线 ←→ 所有模块 (发布/订阅)
07-运行时状态管理 ←→ 所有模块 (读写共享状态)
12-日志监控中心 ←→ 所有模块 (记录日志)
```

> **注意**：当前实现中 UI (MainWindow) 直接持有核心模块引用，未经过 10-参数桥接。10-参数桥接为设计目标层，计划在未来版本中作为 UI↔逻辑 的唯一通道。
