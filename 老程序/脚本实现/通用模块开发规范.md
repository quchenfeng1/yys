# 通用模块开发规范 v1.0

> **文档性质**：如何新增一个通用模块（TaskStep 子类），与现有 9 个模块风格一致  ｜  **配套**：04-任务执行引擎 / 任务设计指导书

---

## 一、什么是通用模块

通用模块是 `tasks/common/` 下的 `TaskStep` 子类，特点是：

- `is_generic = True` — 标记为可跨任务复用
- 不包含副本特定的界面逻辑
- 全项目所有任务都可以 `import` 使用
- 通过 `TaskContext` 获取执行环境（executor / recognizer / config）

**与特化模块的区别**：

| | 通用模块 | 特化模块 |
|------|---------|---------|
| 位置 | `tasks/common/` | `tasks/{daily,permanent,event,special}/` |
| is_generic | `True` | `False` |
| 复用范围 | 全项目 | 单个副本 |
| 示例 | `BattleLoop`, `ClosePopup`, `ReturnHall` | `EnterDungeon`, `SetupSouls` |

## 四、开发步骤

### Step 1：确定模块职责

问自己三个问题：
1. 这个操作是否**多个任务**都需要？（是 → 通用模块）
2. 这个操作是否**不依赖特定副本**的界面？（是 → 通用模块）
3. 这个操作是否需要**从 context.task_config 读取参数**？（是 → 确保配置可从 YAML 配置）

### Step 2：创建文件

在 `tasks/common/` 下创建 `{snake_case_name}.py`。

### Step 3：编写代码

遵循 §三 的标准模板，特别注意：

- `display_name` 和 `description` 使用模块级变量（不是类属性），供 `TaskManager` 解析
- `name` 类属性设为小写下划线格式
- `is_generic = True`
- 所有外部依赖通过 `context` 获取，不要硬编码
- 配置参数从 `context.task_config.get("key", default)` 读取

### Step 4：遵守现有风格

观察现有 9 个模块的共同风格：


## 五、命名约定

| 元素 | 规则 | 示例 |
|------|------|------|
| 文件名 | 小写下划线，描述性强 | `battle_loop.py` / `close_popup.py` |
| 类名 | 大驼峰，动宾/名词 | `BattleLoop` / `ClosePopup` / `ReturnHall` |
| `name` 属性 | 与文件名一致（不含 .py） | `"battle_loop"` |
| `display_name` | 简短中文 | `"战斗循环"` / `"关闭弹窗"` |
| `description` | 一句话功能说明 | `"等待战斗结束→检测胜利/失败→结算"` |
| 构造参数 | 小写下划线，有默认值 | `times: int = 1` |

## 六、timeout 设置指南

| 操作类型 | 建议 timeout | 示例模块 |
|---------|:--:|------|
| 简单点击/关闭 | 10~15s | `ClosePopup` (15s) |
| 页面跳转等待 | 20~30s | `OpenBottomMenu` (15s) |
| 阵容选择 | 20~30s | `SelectTeam` (20s) |
| 单轮战斗 + 结算 | 180~300s | `BattleLoop` (300s) |
| 返回庭院（循环点返回） | 30s | `ReturnHall` (30s) |

**原则**：宁可宽松，不要设 0（无限制）。设 0 的模块一旦卡住会永久阻塞调度循环。

## 七、错误处理

```python
def execute(self, context: TaskContext) -> StepResult:
    exe = context.executor

    # 方案一：操作失败返回 fail（走 TaskGraph error 分支）
    if not exe.click_image("xxx", timeout=5):
        return StepResult.fail("未找到目标按钮")

    # 方案二：条件不满足返回 skip（跳过任务）
    value = context.task_config.get("required", 0)
    if not self._check_condition(value):
        return StepResult.skip("条件不满足，跳过")

    # 方案三：临时故障返回 retry（重新执行当前步骤）
    if not exe.click_image("xxx"):
        return StepResult.retry("加载延迟，重试")

    return StepResult.success("完成")
```

## 九、在 TaskGraph 中使用

```python
def build_graph(context: TaskContext) -> TaskGraph:
    g = TaskGraph("my_task")

    # SETUP
    g.add_step("popup",   ClosePopup())
    g.add_step("stamina", CheckStamina())
    g.add_step("team",    PreCheckTeam())

    # LOOP — 通用模块作为循环体
    g.add_step("battle",  BattleLoop(
        times=context.task_config.get("loop_count", 1)
    ))

    # TEARDOWN
    g.add_step("home",    ReturnHall())

    # 连线
    g.set_entry("popup")
    g.add_edge("popup",   "stamina")
    g.add_edge("stamina", "team")
    g.add_edge("team",    "battle")
    g.add_edge("battle",  "home")
    g.set_error_branch("home")

    return g
```
