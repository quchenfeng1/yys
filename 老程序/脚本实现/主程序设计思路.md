```
16-应用启动引导（ApplicationBootstrap）

  ├── 12-日志监控中心（Monitor）               ← 日志/指标
  ├── 07-运行时状态管理（StateManager）         ← 共享状态
  ├── 10-参数桥接模块（ParamBridge）            ← UI↔程序桥接
  ├── 01-设备连接模块（ConnectionManager）      ← ADB 连接
  ├── 02-图像识别模块（Recognizer）             ← 模板匹配
  ├── 03-防封策略模块（AntiDetect）             ← 行为模拟
  ├── 14-执行器模块（Executor）                ← 02+03+01 的桥接层
  ├── 05-时间调度模块（Scheduler）              ← 任务日程表
  │     ├── RepeatRule                        ← 8种执行规则
  │     └── TaskStateStore                    ← next_run_time 持久化
  ├── 04-任务执行引擎（TaskRegistry）           ← 任务注册与执行
  ├── 13-任务文件管理（TaskManager）            ← 扫描/创建/删除 .py 文件
  ├── 09-运行控制中心（RunController）           ← 三线程调度
  │     ├── 填充线程（FillerThread）            ← 到期任务入队
  │     ├── 执行线程（ExecutorThread）          ← FIFO 出队执行
  │     └── 扫描线程（ScannerThread）           ← 小号维护
  ├── 15-账号管理模块（AccountManager）         ← 账号切换
  └── 11-用户界面模块（MainWindow）            ← PyQt5 三栏布局
```

## 三、运行时数据流

### 3.1 点击启动

```
10-参数桥接模块.RunBridge.request_start()
  → 发布 start_requested 事件
  → 08-事件通信总线 分发
  → 09-运行控制中心._on_start()
     │
     ├── 1. 允许性检查
     │     ├── 调 15-账号管理模块.get_current()
     │     ├── 调 06-配置管理中心.get() → 上限配置
     │     └── 调 01-设备连接模块.is_connected()
     │
     ├── 2. 调 01-设备连接模块.connect()
     ├── 3. 调 05-时间调度模块.load_state()
     ├── 4. 初始化空 FIFO 队列
     ├── 5. 调 07-运行时状态管理.set_state("run_status", "running")
     ├── 6. 启动填充线程 _filler_loop()
     └── 7. 启动执行线程 _executor_loop()
```

### 3.2 三线程调度架构

采用**填充线程 + 执行线程 + 扫描线程**的三线程 FIFO 队列模型（扫描线程负责小号维护，详见 09-运行控制中心 §3.2）：

```
┌─────────────────────────────────────────────────────────────┐
│                    填充线程（_filler_loop）                   │
│  循环（间隔2~3秒）：                                          │
│  ① 熔断检查 → ② 允许性检查 → ③ 调 get_next_task()          │
│  ④ 按优先级排序 → ⑤ FIFO 入队（去重） → ⑥ 更新状态          │
│  ⑦ 发布 schedule_updated → ⑧ 休眠                          │
└──────────────────────────┬──────────────────────────────────┘
                           │  FIFO 队列
                           ▼
┌─────────────────────────────────────────────────────────────┐
│                    执行线程（_executor_loop）                  │
│  循环：                                                      │
│  ① FIFO 出队 → ② 构造 TaskContext → ③ 创建子线程执行        │
│  ④ 处理 TaskResult → ⑤ 调 mark_done() → ⑥ 取下一個          │
└─────────────────────────────────────────────────────────────┘
    ├── ⑥ scheduler.mark_done(name, success)
    └── ⑦ 发布 TASK_DONE → UI 刷新
```

### 3.3 任务执行细节

```
TaskStep.execute(context)
  │  context 包含: executor, recognizer, task_config, log
  │
  ├── context.recognizer.find("主界面/识别-个人名片")
  │     → Recognizer.find(template, region, threshold)
  │     → 截图 → 灰度转换 → cv2.matchTemplate → MatchResult
  │
  ├── context.executor.click_if_exists("主界面/按钮-打开底部菜单")
  │     → Executor.click_if_exists()
  │       ├── Recognizer.find() → 找到?
  │     ├── AntiDetect.random_offset_in_bounds(cx, cy, w, h)  ← 图标矩形内偏移
  │     ├── ADBClient.click(cx, cy)
  │     ├── AntiDetect.sleep(base, jitter)
  │     └── 09-运行控制中心 更新操作计数
  │
  └── return StepResult.success("完成") / StepResult.fail("原因")
```

## 四、事件通信

| 事件名 | 发布者 | 订阅者 | 触发时机 |
|--------|--------|--------|---------|
| `start_requested` | **10-参数桥接模块** | **09-运行控制中心** | 用户点击启动 |
| `stop_requested` | **10-参数桥接模块** | **09-运行控制中心** | 用户点击停止 |
| `pause_requested` | **10-参数桥接模块** | **09-运行控制中心** | 用户点击暂停 |
| `resume_requested` | **10-参数桥接模块** | **09-运行控制中心** | 用户点击恢复 |
| `run_started` | **09-运行控制中心** | **11-用户界面模块** | 运行已开始 |
| `run_paused` | **09-运行控制中心** | **11-用户界面模块** | 运行已暂停 |
| `run_stopped` | **09-运行控制中心** | **11-用户界面模块** | 运行已停止 |
| `run_limit_reached` | **09-运行控制中心** | **09-运行控制中心** + **11-用户界面模块** | 已达上限 |
| `schedule_updated` | **05-时间调度模块** / **09-运行控制中心** | **11-用户界面模块** | 日程表/队列刷新 |
| `task_started` | **09-运行控制中心** | **11-用户界面模块** | 任务开始执行 |
| `task_done` | **09-运行控制中心** | **11-用户界面模块** | 任务执行完成 |
| `task_skipped` | **05-时间调度模块** | **11-用户界面模块** | 任务被跳过 |
| `daily_reset` | **05-时间调度模块** | 模块内部 | 每日00:00 |
| `state_changed` | **07-运行时状态管理** | **11-用户界面模块** | 状态变更 |
| `log_record` | **12-日志监控中心** | **11-用户界面模块** | 新日志产生 |
| `notify_alert` | **12-日志监控中心** | **11-用户界面模块** | 需要用户关注 |
| `config_changed` | **06-配置管理中心** | 各模块（按需过滤） | 配置被修改 |
| `account_switched` | **15-账号管理模块** | **01-设备连接模块** + **07-运行时状态管理** + **05-时间调度模块** | 账号切换 |
| `connection_lost` | **01-设备连接模块** | **11-用户界面模块** | 连接断开 |
| `connection_restored` | **01-设备连接模块** | **11-用户界面模块** | 连接恢复 |
| `connection_error` | **01-设备连接模块** | **11-用户界面模块** | 连接错误 |
